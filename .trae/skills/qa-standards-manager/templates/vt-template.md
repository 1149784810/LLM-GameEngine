## 测试目标

## 截图保存位置

所有截图必须保存在游戏项目目录下的 `screenshots/` 目录：

```
项目根目录/
└── screenshots/                    # 视觉测试截图目录
    ├── vt_startup_*.png           # 启动验证截图
    ├── vt_step_before_*.png       # 操作前截图
    ├── vt_step_after_*.png        # 操作后截图
    ├── vt_button_*.png            # 按钮验证截图
    └── vt_final_*.png             # 最终验证截图
```

## 阻塞式测试流程

### Step 1: 启动验证（阻塞式）

#### 1.1 尝试打开游戏
- [ ] 执行打开游戏命令
- [ ] 记录结果：成功 / 失败

#### 1.2 Web服务器检查（仅当1.1失败时执行）
- [ ] 检查Web服务器是否正常启动
- [ ] 检查端口是否被占用
- [ ] 检查服务是否响应
- [ ] 若服务器正常但游戏打不开 → 直接调用index.html打开
- [ ] 若服务器异常 → 启动服务器后再打开

#### 1.3 截图验证
- [ ] 游戏界面出现后立即截图
- [ ] 截图保存路径: `screenshots/vt_startup_[YYYYMMDD_HHMMSS].png`
- [ ] **【阻塞】等待截图分析完成**

#### 1.4 分析截图确认游戏打开
- [ ] 分析截图内容
- [ ] 确认游戏主界面是否正常显示
- [ ] 确认无错误提示弹窗
- [ ] **【阻塞点】确认游戏确实打开后，才能进入Step 2**
- [ ] 若未打开 → 排查问题 → 修复 → 回到Step 1.1重新验证

#### 启动验证结论
| 状态 | 说明 |
|------|------|
| ✅ 通过 | 游戏正常打开，进入Step 2 |
| ❌ 失败 | 游戏无法打开，需要排查修复 |

---

### Step 2: 读取策划文档规划流程（阻塞式）

#### 2.1 读取策划整合文档
- [ ] 读取UI布局文档
- [ ] 读取功能路径图
- [ ] 确认所有界面和跳转关系

#### 2.2 规划测试步骤
- [ ] 识别所有按钮位置
- [ ] 识别所有入口和跳转点
- [ ] 确定测试优先级顺序
- [ ] 为每个步骤制定验证标准

#### 2.3 生成阻塞式测试计划
- [ ] 输出测试步骤清单
- [ ] **【阻塞点】测试计划确认后，才能进入Step 3**

#### 测试计划输出

| 步骤编号 | 操作描述 | 预期结果 | 截图命名 | 阻塞条件 |

| 3.1 | [操作1] | [预期1] | vt_step_01.png | [阻塞条件1] |
| 3.2 | [操作2] | [预期2] | vt_step_02.png | [阻塞条件2] |
| ... | ... | ... | ... | ... |

### Step 3: 执行阻塞式测试（核心流程）

#### 3.1 [按钮/入口名称]测试

##### 3.1.1 截图操作前界面
- [ ] 截图当前界面
- [ ] 保存路径: `screenshots/vt_step_before_[步骤名]_[时间戳].png`
- [ ] **【阻塞】等待截图保存完成**

##### 3.1.2 分析截图，识别目标元素
- [ ] 分析截图内容
- [ ] 识别[目标元素]位置
- [ ] 确认元素可见且可操作
- [ ] 记录元素坐标位置
- [ ] **【阻塞点】分析完成并确认位置后，才能继续**

##### 3.1.3 执行操作
- [ ] 执行[具体操作]
- [ ] 记录操作时间

##### 3.1.4 截图操作后界面
- [ ] 操作后等待界面响应（最多等待3秒）
- [ ] 截图操作后界面
- [ ] 保存路径: `screenshots/vt_step_after_[步骤名]_[时间戳].png`
- [ ] **【阻塞】等待截图保存完成**

##### 3.1.5 阻塞式分析结果
- [ ] 对比操作前后截图
- [ ] 判断界面是否有变化
- [ ] **【阻塞点】分析完成前不能进行下一步**

**分支A：界面有变化**
- [ ] 确认变化是否符合预期
- [ ] 确认是否正确进入下一界面
- [ ] ✅ 测试通过，进入下一个测试步骤

**分支B：界面无变化**
- [ ] ❌ 点击未生效，需要排查
- [ ] 检查按钮事件是否绑定
- [ ] 检查控制台是否有错误
- [ ] 修复问题
- [ ] **【回归】修复后回到3.1.1重新测试此步骤**
- [ ] 直到点击生效才能继续

##### 3.1.6 记录测试结果
