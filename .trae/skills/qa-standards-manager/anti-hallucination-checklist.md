## 第一部分：测试执行确认（必须逐项勾选）

### 1.1 实际运行确认

- [ ] **我实际启动了游戏/应用**，不是仅阅读代码
- [ ] **我在浏览器/目标环境中运行了项目**
- [ ] **我验证了项目可以正常加载，无启动错误**
- [ ] **我检查了浏览器控制台，记录了所有错误信息**

### 1.2 功能测试确认

- [ ] **我实际点击了每个被标记为"通过"的按钮**
- [ ] **我验证了每个功能点的实际表现**
- [ ] **我测试了边界条件和异常输入**
- [ ] **我记录了实际测试结果，不是仅凭代码推断**

### 1.3 视觉测试确认

- [ ] **我查看了每个界面，确认UI显示正常**
- [ ] **我验证了布局符合设计文档**
- [ ] **我检查了图片、文字、动画的正确性**
- [ ] **我为每个关键界面截图保存**

### 1.4 路径测试确认

- [ ] **我手动走通了每个主流程路径**
- [ ] **我测试了分支路径和异常路径**
- [ ] **我验证了所有按钮入口有效**
- [ ] **我记录了路径中的阻塞点（如有）**

## 第三部分：反幻觉承诺（必须签署）

### 3.1 诚实声明

> 我在此郑重声明：
> 
> 1. **我确实执行了上述测试**，不是虚构或仅凭代码推断
> 2. **我提供的截图和日志真实有效**，不是复制或伪造
> 3. **我记录的测试结果是实际观察到的**，不是假设或推测
> 4. **我理解虚构测试结果将导致测试报告被驳回**

### 3.2 禁止行为确认

我确认在测试过程中**没有**以下行为：

- [ ] 没有仅凭阅读代码判断功能正常
- [ ] 没有假设"看起来应该没问题"
- [ ] 没有复制粘贴之前的测试结果
- [ ] 没有在没有实际测试的情况下勾选通过
- [ ] 没有虚构截图路径或日志内容
- [ ] 没有报告"100%通过"而无具体证据

### 3.3 理解并接受后果

我理解如果被发现存在以下情况，将承担相应后果：

| 违规行为 | 后果 |
|---------|------|
| 虚构测试结果 | 测试报告被驳回，需要重新测试 |
| 伪造截图/日志 | 测试报告被标记为"不可信" |
| 仅凭代码推断 | 要求提供实际测试证据 |
| 复制粘贴模板 | 要求重新填写真实结果 |
| 100%通过无证据 | 强制要求提供额外证据 |

## 第四部分：测试真实性自评

### 4.1 自评问题（必须回答）

**Q1: 你在测试过程中遇到的最大问题是什么？**
> 
> （如果回答"没有问题"，请重新测试，首次测试不可能完美）

**Q2: 有哪些测试项的实际结果与预期不符？**
> 
> （如果回答"全部符合"，请检查是否测试充分）

**Q3: 你是否有任何测试项没有实际执行？**
> 
> （如果有，请列出并说明原因）

**Q4: 你的截图和日志是否真实反映了测试过程？**
> 
> （请确认时间戳和内容的真实性）

### 4.2 自评分数（0-100分）

| 评估维度 | 分数 | 说明 |
|---------|------|------|
| 测试充分性 | __/25 | 是否覆盖了所有关键功能 |
| 证据完整性 | __/25 | 截图和日志是否齐全 |
| 结果真实性 | __/25 | 是否如实记录了问题和失败 |
| 过程可追溯 | __/25 | 是否可以复现测试过程 |
| **总分** | __/100 | |

**评分标准：**
- 90-100分：测试充分，证据完整，结果真实
- 70-89分：测试基本充分，部分证据可补充
- 50-69分：测试有遗漏，需要补充测试
- 0-49分：测试不充分，需要重新测试

## 附录：幻觉检测指标参考

### 常见幻觉信号

| 信号 | 说明 | 处理方式 |
|------|------|---------|
| 100%通过率 | 首次测试不可能全部通过 | 要求提供详细证据 |
| 截图数量少 | 截图数量 < 测试项数×0.5 | 要求补充截图 |
| 0个问题 | 找不到bug是测试不充分 | 要求重新测试 |
| 时间戳异常 | 截图时间与测试时间不符 | 要求重新测试 |
| 模板化描述 | 使用大量模板原文 | 要求填写真实结果 |
| 推断性语言 | "应该"、"看起来"、"理论上" | 要求提供实际证据 |

### 证据质量检查表

| 检查项 | 合格标准 | 检查结果 |
|--------|---------|---------|
| 截图清晰度 | 可辨认UI元素 | □ 合格 □ 不合格 |
| 截图相关性 | 与测试项对应 | □ 合格 □ 不合格 |
| 日志完整性 | 包含测试期间输出 | □ 合格 □ 不合格 |
| 时间一致性 | 时间戳匹配 | □ 合格 □ 不合格 |
| 内容真实性 | 无虚构内容 | □ 合格 □ 不合格 |

## 使用流程

```
测试前：
  1. 阅读本清单，了解反幻觉要求
  2. 准备测试环境和证据收集工具
  3. 确认测试计划和范围

测试中：
  1. 执行实际测试（点击、操作、验证）
  2. 为每个测试项截图
  3. 记录控制台日志
  4. 如实记录通过/失败/阻塞

测试后：
  1. 整理截图和日志到指定目录
  2. 填写本清单（第一至四部分）
  3. 签署诚实声明
  4. 提交给主测试审核

审核时：
  1. 主测试检查清单完整性
  2. 抽查证据真实性
  3. 签署审核意见
  4. 随测试报告一起提交
```
