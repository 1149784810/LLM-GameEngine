## 七、使用指南

### 7.1 新项目启动时
```
1. 确定项目类型 → 查看"按项目类型索引"
2. 确定技术栈 → 查看"按技术栈索引"
3. 获取高风险经验 → 查看"高严重程度"列表
4. 生成《经验借鉴报告》
```

### 7.2 问题排查时
```
1. 提取错误关键词
2. 查看"快速检索标签云"
3. 匹配相关经验记录
4. 应用解决方案
```

### 7.3 流程优化时
```
1. 识别当前流程环节
2. 查看"按问题类型索引"中的流程问题
3. 应用预防措施
```
