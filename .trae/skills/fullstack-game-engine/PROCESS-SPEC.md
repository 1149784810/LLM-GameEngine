## 符号说明

| 符号 | 含义 |
|------|------|
| `→` | 流程流转 |
| `↓` | 步骤执行 |
| `├─→` | 并行分支开始 |
| `└─→` | 并行分支结束 |
| `⛔` | 阻塞点 (BP-XXX) |
| `✅` | 完成/通过 |
| `❌` | 失败/不通过 |
| `[P]` | 输入文档 |
| `[O]` | 输出文档 |
| `[R]` | 角色 |
