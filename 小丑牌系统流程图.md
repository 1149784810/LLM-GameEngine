### 小丑牌触发顺序示例

```
假设装备了以下小丑牌(从左到右):
┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐
│ 小丑A   │  │ 小丑B   │  │ 小丑C   │  │ 小丑D   │  │ 小丑E   │
├─────────┤  ├─────────┤  ├─────────┤  ├─────────┤  ├─────────┤
│筹码+100 │  │倍率+4   │  │倍率x2   │  │筹码+50  │  │倍率x1.5 │
└─────────┘  └─────────┘  └─────────┘  └─────────┘  └─────────┘

触发顺序:
1. 小丑A: 筹码 = 基础筹码 + 100
2. 小丑B: 倍率 = 基础倍率 + 4
3. 小丑C: 倍率 = (基础倍率 + 4) × 2
4. 小丑D: 筹码 = (基础筹码 + 100) + 50
5. 小丑E: 倍率 = ((基础倍率 + 4) × 2) × 1.5

最终计算:
总筹码 = 基础筹码 + 150
总倍率 = (基础倍率 + 4) × 2 × 1.5
```
