# Clicker Quest - 项目信息

## 项目概述

| 项目 | 信息 |
|------|------|
| 项目名称 | Clicker Quest (点击冒险) |
| 项目类型 | Web端连点器放置游戏 |
| 版本 | v1.0 |
| 创建日期 | 2026-02-20 |
| 开发状态 | 开发中 |

## 核心系统

| 系统 | 描述 |
|------|------|
| 金币系统 | 点击获取金币、自动产出、金币显示 |
| 商店系统 | 购买升级、道具购买、价格计算 |
| 道具系统 | 自动点击器、增益道具、限时效果 |
| 成就系统 | 里程碑成就、奖励发放 |
| 排行榜系统 | 本地排名、分数记录 |
| 存档系统 | 自动存档、离线收益、数据持久化 |

## 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **存储**: LocalStorage
- **目标平台**: Web浏览器 (Chrome, Firefox, Edge)

## 美术风格

- **风格**: 卡通扁平化风格
- **色调**: 明亮活泼，橙色、金色、蓝色为主
- **UI**: 简洁现代，圆角设计

## 目标平台

- PC浏览器
- 移动端浏览器（响应式设计）
