## 一、设计规范总览

### 1.1 设计基准

| 项目 | 规格 |
|------|------|
| 设计基准尺寸 | 375 × 812 px (iPhone X) |
| 最小适配尺寸 | 320 × 568 px (iPhone SE) |
| 最大适配尺寸 | 428 × 926 px (iPhone 14 Pro Max) |
| 设计方向 | 竖屏优先 |
| 安全区域 | 顶部44px / 底部34px |

### 1.2 颜色规范

| 颜色名称 | 色值 | 用途 |
|----------|------|------|
| 主色调-金色 | #FFD700 | 金币、重要按钮、高亮元素 |
| 主色调-深金 | #FFA500 | 按钮悬停、进度条 |
| 背景色-主 | #1A1A2E | 主背景 |
| 背景色-次 | #16213E | 卡片背景 |
| 背景色-三 | #0F3460 | 弹窗背景 |
| 文字色-主 | #FFFFFF | 主要文字 |
| 文字色-次 | #B8B8B8 | 次要文字、描述 |
| 文字色-禁用 | #666666 | 禁用状态文字 |
| 强调色-绿 | #4CAF50 | 成功、可购买 |
| 强调色-红 | #F44336 | 错误、不可购买 |
| 强调色-蓝 | #2196F3 | 信息提示 |
| 暴击色-小 | #FFEB3B | 小暴击 |
| 暴击色-中 | #FF9800 | 中暴击 |
| 暴击色-大 | #FFD700 | 大暴击 |

### 1.3 字体规范

| 字体类型 | 字重 | 字号范围 | 用途 |
|----------|------|----------|------|
| 标题字体 | Bold (700) | 24-32px | 界面标题、金币数量 |
| 正文字体 | Regular (400) | 14-16px | 描述文字、商品信息 |
| 数字字体 | Medium (500) | 20-48px | 数值显示、价格 |
| 小字体 | Regular (400) | 10-12px | 提示文字、标签 |

### 1.4 间距规范

| 间距类型 | 数值 | 用途 |
|----------|------|------|
| 超小间距 | 4px | 图标与文字间距 |
| 小间距 | 8px | 同组元素间距 |
| 中间距 | 16px | 不同组元素间距 |
| 大间距 | 24px | 区块间距 |
| 超大间距 | 32px | 页面边距 |

### 1.5 圆角规范

| 元素类型 | 圆角值 |
|----------|--------|
| 按钮 | 8px |
| 卡片 | 12px |
| 弹窗 | 16px |
| 输入框 | 6px |
| 图标容器 | 50% (圆形) |

### 2.2 状态栏区域规格

| 元素 | 规格 | 验收标准 |
|------|------|----------|
| 金币显示 | 宽度120px，高度44px | 金币数量实时更新，数字变化有动画效果 |
| GPS显示 | 宽度100px，高度44px | GPS数值每秒更新，格式为"数字/s" |
| 设置按钮 | 44px × 44px | 点击响应区域≥44px，有悬停效果 |
| 金币图标 | 24px × 24px | 金色💰图标，与文字垂直居中 |
| 数字字体 | 20px Bold | 金色(#FFD700)，右对齐 |

### 2.3 统计区域规格

| 元素 | 规格 | 验收标准 |
|------|------|----------|
| 连击显示 | 宽度80px | 显示当前连击倍率，格式"x1.5" |
| 最高连击 | 宽度90px | 显示历史最高连击数 |
| 暴击率 | 宽度80px | 显示总暴击率百分比 |
| 今日金币 | 宽度100px | 显示今日获得的金币总数 |
| 文字大小 | 12px Regular | 白色(#FFFFFF)，居中对齐 |
| 分隔线 | 1px | 灰色(#666666)，垂直分隔 |

### 2.4 点击按钮区域规格

| 元素 | 规格 | 验收标准 |
|------|------|----------|
| 按钮直径 | 120px | 圆形按钮，居中显示 |
| 按钮背景 | 渐变金色 | 从#FFD700到#FFA500的径向渐变 |
| 按钮边框 | 4px | 白色(#FFFFFF)边框，外发光效果 |
| 点击文字 | 18px Bold | 白色，居中显示"点击我!" |
| 点击图标 | 32px | 👆图标，在文字下方 |
| 点击效果 | 缩放+发光 | 点击时缩小到0.95倍，释放恢复 |
| 冷却动画 | 无 | 无冷却，可连续点击 |
| 飘字动画 | 向上飘动 | 金币数字从按钮位置向上飘动，渐隐消失 |

### 2.5 BUFF状态栏规格

| 元素 | 规格 | 验收标准 |
|------|------|----------|
| 单个BUFF卡片 | 宽度100px，高度50px | 圆角12px，半透明背景 |
| BUFF图标 | 24px × 24px | 左侧显示 |

| 横向滚动 | 超过3个BUFF时可滚动 | 支持左右滑动查看更多BUFF |

### 2.6 底部导航栏规格

| 元素 | 规格 | 验收标准 |

## 八、UI验收标准

### 8.1 视觉验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 颜色一致性 | 与设计稿色值误差≤2% | 取色工具对比 |
| 字体一致性 | 字体类型、大小、粗细完全一致 | 视觉检查 |
| 间距一致性 | 间距误差≤2px | 标尺测量 |
| 圆角一致性 | 圆角误差≤1px | 视觉检查 |
| 图标清晰度 | 无模糊、无锯齿 | 视觉检查 |
| 渐变平滑度 | 无明显色阶 | 视觉检查 |

### 8.2 交互验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 点击响应时间 | ≤50ms | 性能测试工具 |
| 动画帧率 | ≥60 FPS | 性能测试工具 |
| 按钮点击区域 | ≥44px × 44px | 尺寸测量 |
| 滚动流畅度 | 无卡顿、无撕裂 | 视觉检查 |
| 手势响应 | 无延迟、无误触 | 手动测试 |
| 键盘支持 | Tab键可导航 | 键盘测试 |

### 8.3 动画验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 动画时长 | 符合设计规范±50ms | 时间测量 |
| 缓动函数 | 与设计一致 | 视觉检查 |
| 动画连贯性 | 无跳帧、无闪烁 | 视觉检查 |
| 动画性能 | CPU占用≤30% | 性能监控 |
| 动画可中断 | 可随时中断并响应新操作 | 手动测试 |

### 8.4 状态验收标准

| 状态类型 | 验收项 | 标准 |
|----------|--------|------|
| 正常状态 | 所有元素正常显示 | 无遮挡、无错位 |
| 悬停状态 | 鼠标悬停效果明显 | 颜色变化、阴影变化 |
| 点击状态 | 点击反馈清晰 | 缩放、颜色变化 |
| 禁用状态 | 禁用样式明显 | 半透明、灰色 |
| 加载状态 | 加载动画流畅 | 进度指示清晰 |
| 错误状态 | 错误提示明确 | 红色高亮、错误信息 |

### 8.5 可访问性验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 颜色对比度 | 文字对比度≥4.5:1 | 对比度检测工具 |
| 字体可缩放 | 支持200%缩放 | 浏览器缩放测试 |
| 屏幕阅读器 | 支持主要屏幕阅读器 | NVDA/JAWS测试 |
