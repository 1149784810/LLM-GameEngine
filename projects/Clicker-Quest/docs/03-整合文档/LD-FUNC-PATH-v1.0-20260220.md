```
┌─────────────────────────────────────────────────────────────────────────┐
│                           点击事件处理流程                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   [玩家点击按钮]                                                        │
│       │                                                                 │
│       ▼                                                                 │

│       │                                                                 │
│       ▼                                                                 │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ [连击检测]                                                       │  │
│   │     │                                                            │  │
│   │     ├── 时间差 ≤ 500ms ──► comboCount++                          │  │
│   │     │         │                                                  │  │
│   │     │         ▼                                                  │  │
│   │     │   [计算连击倍率]                                           │  │
│   │     │   comboMultiplier = min(1.0 + comboCount × 0.1, 2.0)       │  │
│   │     │                                                            │  │
│   │     └── 时间差 > 500ms ──► comboCount = 1                        │  │
│   │               │                                                  │  │
│   │               ▼                                                  │  │
│   │         [重置连击倍率 = 1.0]                                      │  │

│       │                                                                 │
│       ▼                                                                 │
│   ┌─────────────────────────────────────────────────────────────────┐  │
│   │ [暴击检测]                                                       │  │
│   │     │                                                            │  │
│   │     ├── random < 1% ──► 大暴击 (10x)                             │  │
│   │     │                                                            │  │
│   │     ├── random < 6% ──► 中暴击 (5x)                              │  │
│   │     │                                                            │  │
│   │     ├── random < 16% ──► 小暴击 (2x)                             │  │
│   │     │                                                            │  │
│   │     └── random ≥ 16% ──► 无暴击 (1x)                             │  │
│   └─────────────────────────────────────────────────────────────────┘  │
│       │                                                                 │
│       ▼                                                                 │
│   [计算点击产出]                                                        │
│   gold = (1 + clickPowerLevel)                                         │
│        × (hasDoubleClick ? 2 : 1)                                      │
│        × (1 + goldenTouchLevel × 0.10)                                 │
│        × comboMultiplier                                               │
│        × criticalMultiplier                                            │
│        × buffMultiplier                                                │
│       │                                                                 │
│       ▼                                                                 │
│   [更新金币数量]                                                        │
│   currentGold += gold                                                  │
│   totalGoldEarned += gold                                              │
│       │                                                                 │
│       ▼                                                                 │
│   [更新点击统计]                                                        │
│   totalClicks++                                                        │
│   sessionClicks++                                                      │
│       │                                                                 │
│       ▼                                                                 │
│   [触发成就检测]                                                        │
│       │                                                                 │
│       ▼                                                                 │
│   [播放点击反馈]                                                        │
│   ├── 音效播放                                                         │
│   ├── 金币飘字动画                                                     │
│   └── 按钮动画效果                                                     │
│       │                                                                 │
│       ▼                                                                 │
│   [更新UI显示]                                                          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.3 暴击分支路径

| 暴击类型 | 触发概率 | 分支处理 |
|----------|----------|----------|
| 大暴击 | 1% | 播放金色闪光+粒子效果+强烈震动+金币雨 |
| 中暴击 | 5% | 播放橙色闪光+粒子效果+轻微震动 |
| 小暴击 | 10% | 播放黄色闪光+小粒子效果 |
| 无暴击 | 84% | 播放普通点击音效 |

## 六、离线系统路径

### 6.1 离线收益计算流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           离线收益计算流程                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   [游戏启动]                                                            │
│       │                                                                 │
│       ▼                                                                 │
│   [读取存档中的exitTime]                                                │
│       │                                                                 │
│       ▼                                                                 │
│   [计算离线时间]                                                        │
│   currentTime = Date.now()                                             │
│   offlineMs = currentTime - exitTime                                   │
│   offlineSeconds = Math.floor(offlineMs / 1000)                        │
│       │                                                                 │
│       ▼                                                                 │
│   [检查最小离线时间]                                                    │
│       │                                                                 │
│       ├── offlineSeconds < 60秒 ──► [跳过离线收益] ──► [进入游戏]      │
│       │                                                                 │
│       └── offlineSeconds >= 60秒 ──► 继续                              │
│              │                                                          │
│              ▼                                                          │
│   [限制最大计算时间]                                                    │
│   effectiveSeconds = Math.min(offlineSeconds, 86400)                   │
│       │                                                                 │
│       ▼                                                                 │
│   [读取存档中的GPS]                                                     │
│   lastGPS = saveData.lastGPS                                           │
│       │                                                                 │
│       ▼                                                                 │
│   [计算离线效率]                                                        │
│   timeWarpLevel = saveData.upgrades.time_warp.level                    │
│   efficiency = 0.5 + timeWarpLevel × 0.10                              │
│       │                                                                 │
│       ▼                                                                 │
│   [计算离线收益]                                                        │
│   offlineGold = Math.floor(lastGPS × efficiency × effectiveSeconds)    │
│       │                                                                 │
│       ▼                                                                 │
│   [显示离线收益弹窗]                                                    │
│   ├── 显示离线时间                                                     │
│   ├── 显示获得金币                                                     │
│   └── 显示领取按钮                                                     │
│       │                                                                 │
│       ▼                                                                 │
│   [玩家点击领取]                                                        │
│       │                                                                 │
│       ▼                                                                 │
│   [添加金币]                                                            │
│   currentGold += offlineGold                                           │
│   totalGoldEarned += offlineGold                                       │
│   totalOfflineGold += offlineGold                                      │
│       │                                                                 │
│       ▼                                                                 │
│   [触发离线成就检测]                                                    │
│       │                                                                 │
│       ▼                                                                 │
│   [关闭弹窗，进入游戏]                                                  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 八、边界情况处理

### 8.1 金币上限处理

```
[场景] 金币达到JavaScript Number最大值

[处理流程]
金币即将达到上限
    │
    ▼
[检测金币数量]
    │
    ├── currentGold + gain > MAX_VALUE
    │     │
    │     ▼
    │   [限制金币为MAX_VALUE]
    │   currentGold = MAX_VALUE
    │     │
    │     ▼
    │   [显示上限提示]
    │   "恭喜！你已达到金币上限！"
    │     │
    │     ▼
    │   [显示金币为"MAX"]
    │
    └── currentGold + gain <= MAX_VALUE
          │
          ▼
        [正常添加金币]
```

### 8.2 暴击率上限处理

```
[场景] 暴击率超过100%

[处理流程]
计算总暴击率
    │
    ▼
baseCritRate = 16% (小暴击10% + 中暴击5% + 大暴击1%)
luckyFingerBonus = luckyFingerLevel × 5%
buffBonus = activeBuffs中crit_rate_add总和
    │
    ▼
totalCritRate = baseCritRate + luckyFingerBonus + buffBonus
    │
    ▼
[检查上限]
    │
    ├── totalCritRate > 100%
    │     │
    │     ▼
    │   [限制为100%]
    │   totalCritRate = 100%
    │
    └── totalCritRate <= 100%
          │
          ▼
        [使用实际值]
```

### 8.3 离线时间上限处理

```
[场景] 离线时间超过24小时

[处理流程]
计算离线时间
    │
    ▼
offlineSeconds = (now - exitTime) / 1000
    │
    ▼
[检查上限]
    │
    ├── offlineSeconds > 86400 (24小时)
    │     │
    │     ▼
    │   [限制为24小时]
    │   effectiveSeconds = 86400
    │     │
    │     ▼
    │   [显示提示]
    │   "你离线了超过24小时，收益按24小时计算"
    │
    └── offlineSeconds <= 86400
          │
          ▼
        [使用实际值]
```

### 8.4 价格溢出处理

```
[场景] 商品价格超过JavaScript Number最大值

[处理流程]
计算商品价格
    │
    ▼
price = basePrice × growthRate^level
    │
    ▼
[使用对数运算避免溢出]
logPrice = Math.log(basePrice) + level × Math.log(growthRate)
    │
    ▼
[检查是否超过上限]
    │
    ├── logPrice > 709.78 (ln(1e308))
    │     │
    │     ▼
    │   [返回Infinity]
    │   price = Infinity
    │     │
    │     ▼
    │   [显示为"∞"]
    │
    └── logPrice <= 709.78
          │
          ▼
        [正常计算]
        price = Math.exp(logPrice)
```

### 8.5 快速连续点击处理

```
[场景] 玩家快速连续点击

[处理流程]
连续点击事件

    │
    ├── 每次点击都立即响应
    ├── 不排队等待
    └── 使用高效的事件处理
    │

    │

    └── 使用requestAnimationFrame优化动画
```
