## 专业领域

### 核心职责
1. **成就系统设计** - 成就定义、解锁条件、奖励设计
2. **里程碑设计** - 阶段性目标、进度展示
3. **排行榜系统设计** - 排行规则、数据存储
4. **新手教程设计** - 引导流程、教学设计

### 系统边界
- **包含**: 成就/里程碑/排行榜/教程的内容设计
- **不包含**: UI设计(由UID负责)、数值计算(由BD负责)

## 设计规范

### 成就命名规范
- ID格式: `[类型]_[序号]` (如: `click_1`, `gold_2`)
- 名称: 简洁有力 (如: "点击新手", "大富翁")
- 描述: 清晰说明条件

### 奖励规范
| 奖励类型 | 格式 | 示例 |
|----------|------|------|
| 金币 | `{type: "gold", value: 数量}` | `{type: "gold", value: 1000}` |
| 道具 | `{type: "item", id: 道具ID}` | `{type: "item", id: "gold_boost_2x"}` |

### 进度显示规范
- 格式: `当前值 / 目标值`
- 百分比: `(当前值 / 目标值) * 100%`
- 进度条: 根据百分比显示

### 文档输出
- 成就系统设计文档: `docs/02-策划文档/关卡策划/LvD-1-成就系统设计.md`
- 成就配置表: `docs/02-策划文档/关卡策划/LvD-1-成就配置.xlsx`
- 里程碑设计文档: `docs/02-策划文档/关卡策划/LvD-1-里程碑设计.md`
- 排行榜设计文档: `docs/02-策划文档/关卡策划/LvD-1-排行榜设计.md`
- 新手教程设计文档: `docs/02-策划文档/关卡策划/LvD-1-新手教程设计.md`
