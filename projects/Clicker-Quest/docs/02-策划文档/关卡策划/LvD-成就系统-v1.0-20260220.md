## 1. 系统概述

### 1.1 设计目标

成就系统旨在为玩家提供长期目标和短期挑战，增强游戏的粘性和成就感。通过多样化的成就类型，引导玩家探索游戏的各个方面，同时提供实质性的奖励激励玩家持续游戏。

### 1.2 核心功能

| 功能模块 | 描述 |
|----------|------|
| 成就系统 | 定义、追踪、奖励玩家达成的各种目标 |
| 里程碑系统 | 展示阶段性目标，引导玩家成长方向 |
| 排行榜系统 | 本地排名，激发竞争动力 |
| 新手教程 | 引导新玩家快速上手游戏 |

### 1.3 设计原则

1. **渐进性**: 成就难度由易到难，让玩家逐步成长
2. **多样性**: 覆盖游戏各个方面，鼓励全面体验
3. **奖励性**: 提供实质奖励，增强成就感
4. **可见性**: 进度清晰可见，目标明确

## 2. 成就系统框架

### 2.1 成就分类

成就系统分为5大类，覆盖游戏核心玩法：

| 分类 | ID前缀 | 描述 | 统计维度 |
|------|--------|------|----------|
| 点击类 | `click_` | 与点击次数相关 | 累计点击次数 |
| 金币类 | `gold_` | 与累计金币相关 | 累计获得金币 |
| 升级类 | `upgrade_` | 与购买升级相关 | 累计购买次数 |
| 暴击类 | `crit_` | 与暴击触发相关 | 累计暴击次数 |
| 离线类 | `offline_` | 与离线收益相关 | 累计离线收益 |

### 2.2 成就属性定义

每个成就包含以下属性：

| 属性 | 类型 | 必填 | 描述 |
|------|------|------|------|
| id | string | 是 | 唯一标识符，格式: `[类型]_[序号]` |
| name | string | 是 | 显示名称，简洁有力 |
| description | string | 是 | 成就说明，清晰描述条件 |
| category | string | 是 | 成就分类 |
| condition | object | 是 | 解锁条件 |
| reward | object | 是 | 奖励内容 |
| icon | string | 否 | 成就图标ID |
| hidden | boolean | 否 | 是否隐藏成就，默认false |
| prerequisite | string | 否 | 前置成就ID |

### 2.3 成就状态

成就有三种状态：

| 状态 | 描述 | 触发条件 |
|------|------|----------|
| locked | 未解锁 | 条件未达成 |
| unlocked | 已解锁未领取 | 条件已达成，等待领取 |
| claimed | 已领取 | 玩家已领取奖励 |

### 2.4 进度显示规则

```
进度显示格式: 当前值 / 目标值
进度百分比: (当前值 / 目标值) × 100%
进度条: 根据百分比显示进度条长度
```

**显示示例**:
- 点击达人: 850 / 1,000 (85%)
- 大富翁: 45,230 / 100,000 (45.2%)

## 3. 成就配置表

### 3.1 点击类成就 (click_)

点击类成就追踪玩家的累计点击次数，鼓励玩家持续点击。

| ID | 名称 | 描述 | 条件 | 奖励 | 预计时间 | 难度 |
|----|------|------|------|------|----------|------|
| click_1 | 初次点击 | 完成你的第一次点击 | 点击1次 | 10金币 | 即时 | 入门 |
| click_2 | 点击新手 | 你已经掌握了基础点击 | 点击100次 | 100金币 | 1分钟 | 简单 |
| click_3 | 点击达人 | 点击已经成为习惯 | 点击1,000次 | 500金币 | 10分钟 | 普通 |
| click_4 | 点击大师 | 你的手指非常灵活 | 点击10,000次 | 5,000金币 | 2小时 | 困难 |
| click_5 | 点击传奇 | 点击已成为你的本能 | 点击100,000次 | 50,000金币 | 1天 | 极难 |
| click_6 | 点击之神 | 你的点击超越了凡人 | 点击1,000,000次 | 500,000金币 | 1周 | 传说 |

**设计说明**:
- 成就间隔采用10倍递增，符合玩家成长曲线
- 奖励与难度成正比，激励玩家挑战更高目标
- 预计时间基于平均点击速度(约10次/秒)计算

### 3.2 金币类成就 (gold_)

金币类成就追踪玩家累计获得的金币，是游戏的核心里程碑。

| ID | 名称 | 描述 | 条件 | 奖励 | 预计时间 | 难度 |
|----|------|------|------|------|----------|------|
| gold_1 | 小富翁 | 开始积累你的财富 | 累计1,000金币 | 道具:金币翻倍 | 10分钟 | 简单 |
| gold_2 | 中富翁 | 财富稳步增长 | 累计10,000金币 | 道具:自动加速 | 1小时 | 普通 |
| gold_3 | 大富翁 | 你已经小有成就 | 累计100,000金币 | 道具:金币五倍 | 3小时 | 困难 |
| gold_4 | 超级富翁 | 财富自由不是梦 | 累计1,000,000金币 | 道具:幸运时刻 | 1天 | 极难 |
| gold_5 | 亿万富翁 | 金币对你只是数字 | 累计10,000,000金币 | 道具:金币五倍x3 | 3天 | 传说 |
| gold_6 | 首富 | 你是游戏中最富有的人 | 累计100,000,000金币 | 道具:金币五倍x5 | 1周 | 神话 |

**设计说明**:
- 金币类成就间隔较大，强调里程碑感
- 奖励均为道具，且为稀有道具(无法商店购买)
- 道具奖励与金币获取相关，形成正向循环

### 3.3 升级类成就 (upgrade_)

升级类成就追踪玩家的累计购买次数，鼓励玩家尝试各种升级。

| ID | 名称 | 描述 | 条件 | 奖励 | 预计时间 | 难度 |
|----|------|------|------|------|----------|------|
| upgrade_1 | 升级新手 | 开始投资你的能力 | 购买5次升级 | 200金币 | 5分钟 | 简单 |
| upgrade_2 | 升级达人 | 升级已经成为习惯 | 购买25次升级 | 1,000金币 | 30分钟 | 普通 |
| upgrade_3 | 升级大师 | 你精通各种升级 | 购买100次升级 | 10,000金币 | 3小时 | 困难 |
| upgrade_4 | 升级传奇 | 升级是你的信仰 | 购买500次升级 | 100,000金币 | 1天 | 极难 |

**设计说明**:
- 不限商品类型，任何购买都计入
- 鼓励玩家尝试不同升级路线
- 奖励为金币，帮助玩家继续升级

### 3.4 暴击类成就 (crit_)

暴击类成就追踪玩家的累计暴击次数，鼓励玩家提高暴击率。

| ID | 名称 | 描述 | 条件 | 奖励 | 预计时间 | 难度 |
|----|------|------|------|------|----------|------|
| crit_1 | 暴击新手 | 体验暴击的快感 | 触发10次暴击 | 100金币 | 2分钟 | 简单 |
| crit_2 | 暴击达人 | 暴击已经成为常态 | 触发100次暴击 | 道具:幸运时刻 | 20分钟 | 普通 |
| crit_3 | 暴击大师 | 你是暴击专家 | 触发1,000次暴击 | 道具:金币五倍 | 3小时 | 困难 |
| crit_4 | 暴击传奇 | 每次点击都是惊喜 | 触发10,000次暴击 | 道具:幸运时刻x3 | 1天 | 极难 |

**设计说明**:
- 基础暴击概率16%，触发频率适中
- 包含所有暴击类型(小/中/大暴击)
- 道具奖励与暴击相关(幸运时刻提升暴击率)

### 3.5 离线类成就 (offline_)

离线类成就追踪玩家的累计离线收益，鼓励玩家每日登录。

| ID | 名称 | 描述 | 条件 | 奖励 | 预计时间 | 难度 |
|----|------|------|------|------|----------|------|

| offline_4 | 离线传奇 | 睡觉也在赚钱 | 累计离线收益1,000,000 | 道具:自动加速x3 | 1月 | 极难 |

**设计说明**:
- 鼓励玩家每日登录领取离线收益
- 离线收益基于GPS的50%效率计算
- 道具奖励与自动产出相关

## 5. 排行榜系统设计

### 5.1 排行榜类型

| 类型 | ID | 排序依据 | 描述 |
|------|-----|----------|------|
| 总金币榜 | `rank_gold` | 累计金币 | 按累计获得的金币排名 |
| 点击榜 | `rank_click` | 总点击次数 | 按总点击次数排名 |
| 成就榜 | `rank_achievement` | 完成成就数 | 按完成成就数量排名 |

### 5.2 排行榜规则

**数据存储**:
- 本地存储，无需联网
- 使用localStorage持久化
- 最多保存10条记录

**排名规则**:
- 按分数降序排列
- 相同分数按时间升序排列
- 新记录自动插入正确位置

**数据结构**:
```javascript
{
  rank: 1,                    // 排名
  name: "玩家名",             // 玩家名称
  score: 1000000,             // 分数
  date: "2026-02-20",         // 记录日期
  playTime: 3600              // 游戏时长(秒)
}
```

### 5.3 排行榜显示

| 显示项 | 描述 |
|--------|------|
| 排名 | 1-10名，前三名特殊标识 |
| 名称 | 玩家名称 |
| 分数 | 格式化显示(K/M/B/T) |
| 日期 | 记录创建日期 |
| 变化 | 与上次排名对比(上升/下降/新入榜) |

### 5.4 更新时机

| 时机 | 操作 |
|------|------|
| 游戏结束 | 自动提交当前记录 |
| 手动提交 | 玩家点击"提交成绩"按钮 |
| 突破记录 | 实时更新当前玩家最高记录 |
