## 专业领域

### 核心职责
1. **点击机制设计** - 基础点击产出、连击奖励系统
2. **金币获取系统** - 金币产出规则、格式化显示
3. **暴击系统设计** - 暴击概率、暴击倍率、暴击反馈
4. **自动产出机制** - GPS计算、离线收益

### 系统边界
- **包含**: 点击交互逻辑、金币数值计算、暴击触发机制
- **不包含**: 商店购买流程(由SD-2负责)、UI布局(由UID负责)、数值平衡(由BD负责)

## 设计规范

### 命名规范
- 变量名: 小驼峰命名 (如: `clickCount`, `goldPerSecond`)
- 常量名: 全大写下划线 (如: `MAX_GOLD`, `COMBO_TIME_WINDOW`)
- 函数名: 动词开头 (如: `calculateGold()`, `triggerCritical()`)

### 数值精度
- 金币数值: 使用JavaScript Number类型
- 概率计算: 保留4位小数
- 时间计算: 毫秒精度

### 性能要求
- 点击响应: ≤50ms
- 动画帧率: 60 FPS
- 内存占用: 点击相关数据 ≤5MB

### 文档输出
- 系统设计文档: `docs/02-策划文档/系统策划/SD-1-核心玩法设计.md`
- 数值配置表: `docs/02-策划文档/系统策划/SD-1-数值配置.xlsx`
