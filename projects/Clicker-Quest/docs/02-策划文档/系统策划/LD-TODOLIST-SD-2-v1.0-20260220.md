# Clicker Quest - SD-2 系统策划任务清单

## 任务概览

| 项目 | 内容 |
|------|------|
| 项目名称 | Clicker Quest (点击冒险) |
| 子策划角色 | SD-2 系统策划-商店道具 |

---

## 专业领域

### 核心职责
1. **商店系统设计** - 商品定义、购买流程、价格增长机制
2. **道具系统设计** - 道具类型、获取方式、使用效果
3. **升级系统关联** - 升级效果与核心玩法的对接

### 系统边界
- **包含**: 商店UI逻辑、道具效果逻辑、购买验证
- **不包含**: 点击机制(由SD-1负责)、数值平衡(由BD负责)、UI布局(由UID负责)

## 设计任务清单

### 任务 SD-2-001: 商店商品定义

| 属性 | 内容 |
|------|------|
| 任务ID | SD-2-001 |
| 优先级 | P0 (核心功能) |
| 任务描述 | 定义商店中所有商品的属性和效果 |
| 详细内容 | 定义8种商品:<br>1. **点击强化** (click_power): 基础价10, 点击+1, 增长1.15x<br>2. **自动点击器** (auto_clicker): 基础价100, GPS+1, 增长1.15x<br>3. **双击** (double_click): 基础价500, 点击x2, 增长1.5x<br>4. **幸运手指** (lucky_finger): 基础价1000, 暴击率+5%, 增长1.3x<br>5. **黄金之手** (golden_touch): 基础价5000, 全金币+10%, 增长1.4x<br>6. **时间扭曲** (time_warp): 基础价10000, 离线+10%, 增长1.5x<br>7. **超级点击器** (mega_clicker): 基础价50000, GPS+10, 增长1.2x<br>8. **暴击大师** (critical_master): 基础价100000, 暴击伤+50%, 增长1.3x |
| 验收标准 | 1. 所有商品属性定义完整<br>2. 商品ID唯一且有意义<br>3. 效果描述清晰准确<br>4. 价格增长公式正确 |
| 依赖任务 | 无 |
| 预计工时 | 3小时 |

### 任务 SD-2-004: 价格增长机制设计

| 属性 | 内容 |
|------|------|
| 任务ID | SD-2-004 |
| 优先级 | P1 (重要功能) |
| 任务描述 | 设计商品价格的增长计算公式 |
| 详细内容 | 价格计算公式:<br>`新价格 = 基础价格 × (增长率 ^ 当前等级)`<br><br>示例计算:<br>- 点击强化 Lv.5: 10 × 1.15^5 = 20.1<br>- 自动点击器 Lv.3: 100 × 1.15^3 = 152.1<br><br>价格显示规则:<br>- 向上取整显示<br>- 使用金币格式化规则 |
| 验收标准 | 1. 价格计算公式正确<br>2. 价格增长符合设计预期<br>3. 价格显示格式正确<br>4. 高等级价格不溢出 |
| 依赖任务 | SD-2-001 |
| 预计工时 | 2小时 |

## 设计规范

### 商品命名规范
- 商品ID: 小写下划线 (如: `click_power`, `auto_clicker`)
- 显示名称: 中文简洁 (如: "点击强化", "自动点击器")

### 道具命名规范
- 道具ID: 小写下划线 (如: `gold_boost_2x`, `lucky_hour`)
- 显示名称: 中文简洁 (如: "金币翻倍", "幸运时刻")

### 数据结构规范
```javascript
// 商品数据结构
{
  id: "click_power",
  name: "点击强化",
  basePrice: 10,
  currentPrice: 20,
  level: 5,
  growthRate: 1.15,
  effect: { type: "click_add", value: 1 }
}

// 道具数据结构
{
  id: "gold_boost_2x",
  name: "金币翻倍",
  effect: { type: "gold_multiplier", value: 2 },
  duration: 30,
  source: "shop"
}
```
