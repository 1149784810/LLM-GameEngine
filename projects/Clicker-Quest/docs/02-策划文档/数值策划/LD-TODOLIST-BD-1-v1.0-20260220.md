## 专业领域

### 核心职责
1. **经济系统设计** - 金币产出与消耗平衡
2. **价格体系设计** - 商品价格计算与增长曲线
3. **成长曲线设计** - 玩家成长节奏控制
4. **数值验证** - 数值合理性测试与调整

## 设计规范

### 数值精度
- 金币: 整数，最大1e308
- 概率: 保留4位小数
- 倍率: 保留2位小数
- 时间: 秒级精度

### 公式规范
```
// 价格计算
currentPrice = basePrice * Math.pow(growthRate, level)

// GPS计算
totalGPS = autoClickerLevel * 1 + megaClickerLevel * 10
totalGPS *= (1 + goldenTouchBonus)

// 点击产出计算
clickOutput = baseClick + clickPowerLevel
clickOutput *= doubleClickMultiplier
clickOutput *= (1 + goldenTouchBonus)

// 暴击期望
critExpectation = normalRate * 1 + smallCritRate * 2 + midCritRate * 5 + bigCritRate * 10
```
