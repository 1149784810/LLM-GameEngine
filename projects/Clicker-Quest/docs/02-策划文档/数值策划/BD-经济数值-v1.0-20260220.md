## 一、设计概述

### 1.1 设计目标

本数值体系旨在为Clicker Quest连点器游戏构建一个**稳定、可持续、有趣**的经济系统：

| 目标 | 描述 |
|------|------|
| 短期目标 | 新手玩家5分钟内获得成就感，理解游戏核心循环 |
| 中期目标 | 1-10小时游戏时间内，玩家持续有明确目标 |
| 长期目标 | 数值增长可控，避免后期数值膨胀过快或停滞 |

### 1.2 核心设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                    数值设计核心原则                          │
├─────────────────────────────────────────────────────────────┤
│  1. 指数增长控制 - 使用合理的增长率防止数值爆炸              │
│  2. 多系统平衡 - 点击产出与GPS产出保持合理比例              │
│  3. 激励反馈 - 短期快速反馈 + 长期目标追求                  │
│  4. 离线友好 - 离线收益鼓励每日登录但不强制                 │
│  5. 可扩展性 - 为后续更新预留数值空间                       │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 数值精度规范

| 数据类型 | 精度要求 | 最大值 | 说明 |
|----------|----------|--------|------|
| 金币 | 整数 | 1e308 | JavaScript Number最大值 |
| 概率 | 4位小数 | 1.0000 | 百分比形式存储 |
| 倍率 | 2位小数 | 无限制 | 加成系数 |
| 时间 | 秒级 | - | 时间戳计算 |

#### 2.1.2 暴击系统配置

| 暴击类型 | 概率 | 倍率 | 期望贡献 |
|----------|------|------|----------|
| 普通攻击 | 84.00% | 1.0x | 0.8400 |

| 大暴击 | 1.00% | 10.0x | 0.1000 |

**暴击期望产出公式**:
```
E[暴击产出] = Σ(概率_i × 倍率_i)
           = 0.84×1 + 0.10×2 + 0.05×5 + 0.01×10
           = 0.84 + 0.20 + 0.25 + 0.10
           = 1.39 金币/点击
```

| 完美连击+大暴击 | 1 × 2.0 × 10 | 20 金币 |

### 3.1 价格计算公式

**核心公式**:
```
当前价格 = 基础价格 × (增长率 ^ 当前等级)
```

**JavaScript实现**:
```javascript
function calculatePrice(basePrice, growthRate, level) {
    return Math.floor(basePrice * Math.pow(growthRate, level));
}
```

### 4.1 GPS来源分析

| 黄金之手 | - | +10%/级 | 乘法加成 |

### 4.2 GPS计算公式

**基础GPS**:
```
baseGPS = autoClickerLevel × 1 + megaClickerLevel × 10
```

**加成后GPS**:
```
totalGPS = baseGPS × (1 + goldenTouchLevel × 0.10)
```

**完整公式**:
```javascript
function calculateGPS(autoClickerLevel, megaClickerLevel, goldenTouchLevel) {
    const baseGPS = autoClickerLevel * 1 + megaClickerLevel * 10;
    const bonus = 1 + goldenTouchLevel * 0.10;
    return baseGPS * bonus;
}
```

## 五、点击产出成长曲线设计

### 5.1 点击产出来源

| 来源 | 效果类型 | 计算方式 |
|------|----------|----------|
| 基础 | 固定值 | 1 金币 |
| 点击强化 | 加法 | +等级 金币 |
| 双击 | 乘法 | ×2 |
| 黄金之手 | 乘法 | ×(1 + 等级×0.10) |
| 暴击大师 | 暴击倍率加成 | 暴击伤害×(1 + 等级×0.50) |

### 5.2 点击产出计算公式

**基础点击产出**:
```
baseClick = 1 + clickPowerLevel
```

**加成后点击产出**:
```
clickOutput = baseClick × doubleClickMultiplier × (1 + goldenTouchLevel × 0.10)
```

**暴击加成后**:
```
critMultiplier = baseCritMultiplier × (1 + criticalMasterLevel × 0.50)
```

**完整公式**:
```javascript
function calculateClickOutput(clickPowerLevel, hasDoubleClick, goldenTouchLevel) {
    const baseClick = 1 + clickPowerLevel;
    const doubleMultiplier = hasDoubleClick ? 2 : 1;
    const goldenBonus = 1 + goldenTouchLevel * 0.10;
    return baseClick * doubleMultiplier * goldenBonus;
}
```

## 六、离线收益数值设计

### 6.1 离线收益规则

| 参数 | 数值 | 说明 |
|------|------|------|
| 基础效率 | 50% | 离线时GPS效率减半 |
| 时间上限 | 24小时 | 最长计算时间 |
| 加成来源 | 时间扭曲 | 每级+10%效率 |

### 6.2 离线收益计算公式

**基础公式**:
```
离线收益 = GPS × 50% × 离线时间(秒) × (1 + 时间扭曲加成)
```

**时间扭曲加成**:
```
时间扭曲加成 = timeWarpLevel × 0.10
```

**完整公式**:
```javascript
function calculateOfflineReward(gps, offlineSeconds, timeWarpLevel) {
    const maxOfflineSeconds = 24 * 60 * 60; // 24小时
    const effectiveSeconds = Math.min(offlineSeconds, maxOfflineSeconds);
    const baseEfficiency = 0.50;
    const timeWarpBonus = 1 + timeWarpLevel * 0.10;
    return gps * baseEfficiency * effectiveSeconds * timeWarpBonus;
}
```

### 6.3 离线收益示例计算

#### 示例1: 基础离线收益

| 参数 | 数值 |
|------|------|
| GPS | 100 |
| 离线时间 | 8小时 |
| 时间扭曲等级 | 0 |

**计算**:
```
收益 = 100 × 0.5 × (8 × 3600) × 1.0
     = 100 × 0.5 × 28,800 × 1.0
     = 1,440,000 金币
```

#### 示例2: 高级离线收益

| 参数 | 数值 |
|------|------|
| GPS | 1,000 |
| 离线时间 | 24小时 |
| 时间扭曲等级 | 5 |

**计算**:
```
收益 = 1,000 × 0.5 × (24 × 3600) × 1.5
     = 1,000 × 0.5 × 86,400 × 1.5
     = 64,800,000 金币
```

### 6.5 离线收益设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                    离线收益设计原则                          │
├─────────────────────────────────────────────────────────────┤
│  1. 鼓励每日登录 - 离线收益有吸引力但不过分                 │
```

### 7.2 道具性价比分析

#### 7.2.1 金币翻倍 (gold_boost_2x)

**盈亏平衡点计算**:
```
收益 = (点击产出 + GPS) × 2 × 30秒
成本 = 5,000 金币

盈亏平衡点: (点击产出 + GPS) × 60 = 5,000
点击产出 + GPS = 83.3 金币/秒
```

**结论**: 当总产出 > 83.3/秒 时购买划算

| 场景 | 产出/秒 | 30秒收益 | 净收益 |
|------|---------|----------|--------|
| 新手 | 10 | 600 | -4,400 |
| 初级 | 50 | 3,000 | -2,000 |
| 中级 | 100 | 6,000 | +1,000 |
| 高级 | 500 | 30,000 | +25,000 |

#### 7.2.2 自动加速 (auto_boost)

**盈亏平衡点计算**:
```
收益 = GPS × 3 × 60秒
成本 = 20,000 金币

盈亏平衡点: GPS × 180 = 20,000
GPS = 111.1 金币/秒
```

**结论**: 当GPS > 111.1/秒 时购买划算

| 场景 | GPS | 60秒收益 | 净收益 |
|------|-----|----------|--------|
| 新手 | 10 | 1,800 | -18,200 |
| 初级 | 50 | 9,000 | -11,000 |
| 中级 | 150 | 27,000 | +7,000 |
| 高级 | 500 | 90,000 | +70,000 |

#### 7.2.3 即时金币 (instant_gold)
