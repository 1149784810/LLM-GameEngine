# Clicker Quest - UID-1 UI策划任务清单

## 任务概览

| 项目 | 内容 |
|------|------|
| 项目名称 | Clicker Quest (点击冒险) |
| 子策划角色 | UID-1 UI策划-主界面 |

## 专业领域

### 核心职责
1. **主界面布局设计** - 整体界面结构、元素排布
2. **点击按钮设计** - 按钮样式、交互反馈
3. **金币显示设计** - 金币数值展示、DPS显示
4. **导航系统设计** - 底部导航栏、页面切换

### 系统边界
- **包含**: 主界面UI布局、点击交互UI、导航UI
- **不包含**: 商店界面UI(由UID-2负责)、系统逻辑(由SD负责)

## 设计规范

### 颜色规范
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色调 | #FF9800 | 橙色，用于按钮、强调 |
| 金币色 | #FFD700 | 金色，用于金币相关 |
| 成功色 | #4CAF50 | 绿色，用于DPS、成功提示 |
| 信息色 | #2196F3 | 蓝色，用于导航、链接 |
| 警告色 | #FF5722 | 橙红色，用于暴击、警告 |
| 背景色 | #F5F5F5 | 浅灰色，用于背景 |
| 文字色 | #333333 | 深灰色，用于正文 |

### 字体规范
| 用途 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 金币数字 | 32px | Bold | #FFD700 |
| DPS显示 | 16px | Regular | #4CAF50 |
| 标题 | 20px | Bold | #333333 |
| 正文 | 14px | Regular | #333333 |
| 小字 | 12px | Regular | #666666 |

### 间距规范
- 页面边距: 16px
- 元素间距: 8px
- 内边距: 12px
- 圆角: 8px (大元素), 4px (小元素)

### 动画规范
- 时长: 0.1s (快速), 0.2s (标准), 0.3s (慢速), 0.5s (飘字)
- 缓动: ease-out (默认), ease-out-back (弹性)
- 帧率: 60 FPS
