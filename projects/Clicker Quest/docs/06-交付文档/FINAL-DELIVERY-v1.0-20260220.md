## 核心功能

### 已实现功能

| 系统 | 功能 | 状态 |
|------|------|------|
| 点击系统 | 点击获取金币、暴击系统（小/中/大暴击） | ✅ 完成 |
| 金币系统 | 金币管理、格式化显示（K/M/B/T）、DPS计算 | ✅ 完成 |
| 商店系统 | 商品列表、购买流程、价格计算 | ✅ 完成 |
| 道具系统 | 自动点击器、增益道具、限时效果 | ✅ 完成 |
| 成就系统 | 25个成就、里程碑奖励 | ✅ 完成 |
| 存档系统 | 自动存档、离线收益、数据加密 | ✅ 完成 |
| 排行榜系统 | 本地排名 | ✅ 完成 |

### 美术资源

- **风格**: 二次元动漫风格
- **角色**: AI生成的Q版二次元角色
- **色调**: 明亮活泼，粉色、蓝色、金色为主

## 技术栈

- **前端**: HTML5 Canvas + JavaScript (ES6+) + CSS3
- **存储**: LocalStorage
- **目标平台**: Web浏览器 (Chrome, Firefox, Edge)
