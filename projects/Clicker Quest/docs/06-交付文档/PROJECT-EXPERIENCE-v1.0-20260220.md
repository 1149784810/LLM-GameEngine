## 核心经验总结

### 1. 流程规范的重要性

**经验**：严格按照全栈游戏开发引擎的流程执行，确保每个阶段的阻塞点都正确解锁后再进入下一阶段。

**具体实践**：
- Stage 1-1 → Stage 1-2 → Stage 1-3 顺序执行
- 子策划并行设计，最大化效率
- 主程序员只读取整合文档，避免信息混乱

### 2. 并行调度的效率

**经验**：在允许并行的阶段，同时启动多个智能体，显著提升开发效率。

**具体实践**：
- Stage 1-2：12个子策划同时工作
- Stage 2-2：10个子程序员同时开发
- 遵循"应上尽上"原则

### 3. AI生成资产的应用

**经验**：使用AI工具生成二次元风格资产，快速获得高质量美术资源。

**具体实践**：
- 调用 mcp_liblib-ai-picture_generate_and_wait 生成角色图片
- 直接应用到游戏界面中

### 4. 测试驱动的质量保障

**经验**：QA测试阶段发现的问题越早修复，成本越低。

**具体实践**：
- 功能测试(FT)覆盖所有核心功能
- 测试通过率100%确保交付质量
