## 1. 设计规范总览

### 1.1 设计原则

| 原则 | 描述 | 实施要点 |
|------|------|---------|
| 简洁直观 | 界面元素精简，功能一目了然 | 核心功能不超过3次点击到达 |
| 反馈及时 | 用户操作即时响应 | 所有交互在100ms内给予视觉反馈 |
| 层级清晰 | 信息层次分明，重点突出 | 使用颜色、大小、位置区分优先级 |
| 风格统一 | 全局视觉语言一致 | 统一色彩、字体、图标风格 |
| 适配友好 | 多设备多分辨率适配 | 支持竖屏/横屏，多分辨率自适应 |

## 附录B: 切图命名规范

```
命名格式: [类型]_[名称]_[状态]_[尺寸].[格式]

示例:
- btn_primary_normal@2x.png
- btn_primary_pressed@2x.png
- icon_coin@3x.png
- card_item_bg@2x.png
- bg_main@2x.jpg

类型缩写:
- btn: 按钮
- icon: 图标
- bg: 背景
- card: 卡片
- img: 图片
- txt: 文字图片

状态缩写:
- normal: 正常
- pressed: 按下
- disabled: 禁用
- selected: 选中
- hover: 悬停

倍率:
- @1x: 1倍图 (基准)
- @2x: 2倍图 (Retina)
- @3x: 3倍图 (高清)
```
