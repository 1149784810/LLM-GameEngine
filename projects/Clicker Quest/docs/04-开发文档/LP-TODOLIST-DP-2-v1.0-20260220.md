## 三、叠加规则

| 叠加类型 | 英文标识 | 说明 |
|---------|---------|------|
| 可叠加 | STACKABLE | 效果累加，无上限 |
| 刷新叠加 | REFRESH | 效果不累加，刷新时间 |
| 上限叠加 | CAP | 效果累加，有上限 |
| 不可叠加 | NON_STACKABLE | 效果不累加，不刷新 |

## 五、实现详情

### 5.1 全局倍率管理
- 实现了 `globalMultipliers` 对象，管理金币、点击和DPS三种倍率
- 支持永久道具对全局倍率的修改
- 倍率更新时自动触发事件通知

### 5.2 BUFF叠加系统
- 实现了四种叠加类型的完整逻辑
- STACKABLE: 时长相加，层数累加
- REFRESH: 重置时长，保持效果
- CAP: 有上限的叠加，防止无限增长
- NON_STACKABLE: 独立存在，不叠加

### 5.3 BUFF过期处理
- 每100ms更新一次BUFF状态
- 自动检测并移除过期BUFF
- 过期时触发事件通知

### 5.4 倍率计算
- `calculateGoldMultiplier()`: 计算金币倍率
- `calculateClickMultiplier()`: 计算点击倍率
- `calculateDPSBonus()`: 计算DPS加成
- `calculateCritRateBonus()`: 计算暴击率加成
