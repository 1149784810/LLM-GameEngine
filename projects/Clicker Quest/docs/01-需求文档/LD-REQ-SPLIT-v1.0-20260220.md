## 一、项目概述

### 1.1 项目基本信息
- **项目名称**: Clicker Quest (点击冒险)
- **项目类型**: Web端连点器放置游戏
- **技术栈**: HTML5 Canvas + JavaScript (ES6+) + CSS3
- **美术风格**: 二次元动漫风格
- **目标平台**: Web浏览器 (PC/Mobile)

### 1.2 核心玩法
玩家通过点击屏幕获取金币，使用金币购买升级和道具，逐步提升金币获取效率。游戏采用放置类玩法，即使离线也能获得收益。

### 1.3 目标用户
- 喜欢休闲放置类游戏的玩家
- 追求成就感和数值成长的玩家
- 碎片化时间游戏玩家

## 二、核心系统拆分

### 2.1 点击系统 (SD-1负责)
**系统描述**: 玩家点击屏幕获取金币的核心机制

**核心功能**:
- 基础点击：每次点击获得基础金币
- 暴击机制：概率触发暴击，获得多倍金币
- 点击反馈：视觉和音效反馈
- 点击升级：可升级每次点击获得的金币数

**关键参数**:
- 基础点击金币: 1
- 暴击倍率: 2x/5x/10x
- 暴击概率: 基础5%，可通过道具提升

### 2.2 金币系统 (SD-1负责)
**系统描述**: 游戏经济系统的核心

**核心功能**:
- 金币显示：实时显示当前金币数量
- DPS显示：显示每秒金币产出
- 金币获取：点击、自动点击器、成就奖励
- 金币消耗：购买升级、道具

**关键参数**:
- 金币精度: 整数，支持大数值显示(K/M/B/T)
- DPS计算: 所有自动点击器产出总和

### 2.3 商店系统 (SD-2负责)
**系统描述**: 玩家购买升级和道具的界面

**核心功能**:
- 道具列表：展示可购买的道具
- 购买流程：点击购买→扣除金币→获得道具
- 价格显示：显示道具价格和购买后效果
- 购买限制：部分道具有购买数量限制

**UI布局**:
- 顶部：分类标签(升级/道具/特殊)
- 中部：道具卡片列表(图标+名称+价格+效果)
- 底部：购买按钮

### 2.4 道具系统 (SD-3负责)
**系统描述**: 游戏内各种增益道具

**道具类型**:
1. **自动点击器**: 每秒自动获得金币
2. **金币翻倍**: 限时金币获取翻倍
3. **幸运药水**: 限时提升暴击率
4. **时间加速**: 限时加速自动点击器效率
5. **离线收益**: 提升离线金币收益比例

**道具属性**:
- 道具ID
- 道具名称
- 道具描述
- 道具价格
- 道具效果类型
- 道具效果数值
- 道具持续时间(限时道具)

### 2.5 成就系统 (LvD-1负责)
**系统描述**: 里程碑奖励系统

**成就类型**:
- 点击次数成就: 累计点击100/1000/10000次
- 金币成就: 累计获得1K/1M/1B金币
- 道具成就: 购买特定数量道具
- 时间成就: 游戏时长里程碑

**奖励机制**:
- 金币奖励
- 特殊道具
- 称号/徽章

### 2.6 排行榜系统 (SD-4负责)
**系统描述**: 本地排名系统

**排名依据**:
- 总金币数量
- DPS数值
- 游戏时长

**功能**:
- 显示前10名玩家数据
- 本地存储排名记录
- 支持重置排行榜

### 2.7 存档系统 (SD-4负责)
**系统描述**: 游戏数据持久化

**存档内容**:
- 金币数量
- 道具库存
- 成就进度
- 游戏设置
- 游戏时长

**存档机制**:
- 自动存档: 每30秒自动保存
- 离线存档: 关闭游戏时保存
- 离线收益: 根据离线时长计算收益

## 四、数值系统拆分

### 4.1 经济曲线 (BD-1负责)
**设计目标**:
- 前期(0-10分钟): 快速成长，建立成就感
- 中期(10-60分钟): 稳定成长，解锁新内容
- 后期(1小时+): 缓慢成长，追求极限

**金币产出曲线**:
- 点击产出: 指数增长
- 自动产出: 线性增长
- 总产出: 混合增长

### 4.2 道具定价 (BD-2负责)
**定价原则**:
- 基础道具: 便宜，快速购买
- 高级道具: 昂贵，长期目标
- 特殊道具: 稀有，限时活动

**价格曲线**:
- 自动点击器: 100/500/2K/10K/50K...
- 金币翻倍: 1K/5K/25K...
- 幸运药水: 500/2.5K/12.5K...

### 4.3 升级成本 (BD-3负责)
**升级类型**:
- 点击金币升级: 提升每次点击获得的金币
- 自动点击器升级: 提升自动点击器效率
- 暴击率升级: 提升暴击概率

**成本曲线**:
- 升级成本: 指数增长
- 升级效果: 线性增长
