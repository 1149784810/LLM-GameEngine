## 一、任务概览

作为UI策划-商店界面(UID-2)，你负责设计Clicker Quest游戏的商店界面。商店界面是玩家购买道具的主要场所，界面设计直接影响玩家的购买决策和游戏经济。

**核心目标**:
- 设计清晰易用的商店界面
- 创造有吸引力的道具卡片设计
- 确保购买流程顺畅

**优先级**: P1 (重要功能，优先完成)

---

## 二、专业领域

### 2.1 核心能力要求
- **UI设计能力**: 能够设计美观易用的商店界面
- **商业思维**: 理解玩家购买心理和决策过程
- **信息架构能力**: 能够组织复杂的道具信息

## 三、设计任务清单

### 任务1: 商店界面布局设计

**任务ID**: UID-2-TASK-001
**优先级**: P0 (最高)
**任务描述**: 设计商店界面的整体布局和元素分布

**设计要点**:
1. 界面布局结构
   ```
   +----------------------------------+
   |  [升级] [道具] [特殊]            |  <- 分类标签
   +----------------------------------+
   |  +------------------------+      |
   |  | [图标] 道具名称        |      |  <- 道具卡片
   |  | 效果描述               |      |
   |  | 价格: 100金币  [购买]  |      |
   |  +------------------------+      |
   |  +------------------------+      |
   |  | [图标] 道具名称        |      |
   |  | 效果描述               |      |
   |  | 价格: 500金币  [购买]  |      |
   |  +------------------------+      |
   +----------------------------------+
   ```

2. 分类标签设计
   - 标签数量: 3个(升级/道具/特殊)
   - 标签尺寸: 宽度33.3%，高度50px
   - 标签状态: 未选中/选中
   - 标签样式: 符合二次元风格

3. 道具列表区域
   - 列表区域: 占据主要空间
   - 滚动方式: 垂直滚动
   - 卡片间距: 10px
   - 列表边距: 上下左右各20px

**输出交付**:
- [商店界面布局设计文档](../../02-策划文档/UI策划/商店界面布局设计.md)
- 商店界面布局图(图片格式)

**验收标准**:
- [ ] 界面布局合理，符合用户习惯
- [ ] 分类标签设计清晰
- [ ] 道具列表区域设计合理
- [ ] 文档完整，包含所有设计要点

### 任务2: 道具卡片设计

**任务ID**: UID-2-TASK-002
**优先级**: P0 (最高)
**任务描述**: 设计道具卡片的样式和信息展示

**设计要点**:
1. 卡片布局
   - 卡片尺寸: 宽度100%，高度120px
   - 卡片布局: 图标(左) + 信息(中) + 按钮(右)
   - 卡片圆角: 10px
   - 卡片阴影: 轻微阴影效果

2. 卡片元素
   - 道具图标: 80x80px，左侧居中
   - 道具名称: 字体大小18px，加粗
   - 效果描述: 字体大小14px，灰色
   - 价格显示: 字体大小16px，金色
   - 购买按钮: 80x40px，右侧居中

3. 卡片状态
   - 可购买状态: 正常显示
   - 不可购买状态: 灰色显示，按钮禁用
   - 已购买状态: 显示"已拥有"标识
   - 限时状态: 显示剩余时间

## 六、风险提示

### 6.1 信息过载风险
**风险描述**: 道具信息过多，玩家难以理解
**应对措施**: 优化信息展示，使用图标和颜色区分

### 6.2 性能风险
**风险描述**: 道具过多导致加载缓慢
**应对措施**: 虚拟列表、懒加载、优化资源

### 6.3 用户体验风险
**风险描述**: 购买流程复杂，影响转化率
**应对措施**: 简化购买流程，优化交互反馈
