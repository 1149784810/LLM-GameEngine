## 一、任务概览

作为UI策划-动效设计(UID-3)，你负责设计Clicker Quest游戏的所有动效。动效是提升游戏体验和反馈感的重要元素，直接影响玩家的操作手感和游戏乐趣。

**核心目标**:
- 设计流畅自然的金币飘字动效
- 创造有冲击力的按钮反馈动效
- 设计华丽的暴击特效
- 确保动效性能优化

**优先级**: P0 (核心功能，必须优先完成)

## 三、设计任务清单

### 任务1: 金币飘字动效设计

**任务ID**: UID-3-TASK-001
**优先级**: P0 (最高)
**任务描述**: 设计点击后金币数字向上飘动的动效

**设计要点**:
1. 飘字动画
   - 初始位置: 点击位置
   - 移动方向: 向上飘动
   - 移动距离: 100-150px
   - 移动时长: 800-1000ms

2. 飘字样式
   - 字体大小: 24-32px
   - 字体颜色: 金色(#FFD700)
   - 字体描边: 黑色描边，增强可读性
   - 字体效果: 加粗，发光效果

3. 飘字效果
   - 透明度变化: 从100%渐变到0%
   - 缩放变化: 从1.2倍缩小到0.8倍
   - 随机偏移: 左右随机偏移20-30px
   - 多个飘字: 支持同时显示多个飘字

4. 暴击飘字
   - 字体大小: 36-48px
   - 字体颜色: 红色(#FF4500)或彩虹色
   - 特效: 震动效果，更大发光范围
   - 显示时长: 1200-1500ms

- 动效演示(GIF/视频格式)

### 任务2: 按钮反馈动效设计

**任务ID**: UID-3-TASK-002
**优先级**: P0 (最高)
**任务描述**: 设计点击按钮时的反馈动效

**设计要点**:
1. 点击缩放动效
   - 默认状态: 缩放比例1.0
   - 点击瞬间: 缩放比例0.9
   - 恢复时间: 100-150ms
   - 缓动函数: ease-out

2. 点击震动动效
   - 震动幅度: 2-5px
   - 震动方向: 左右震动
   - 震动次数: 2-3次
   - 震动时长: 100-150ms

3. 点击发光动效
   - 发光颜色: 白色/金色
   - 发光范围: 按钮周围
   - 发光时长: 200-300ms
   - 发光强度: 从强到弱

4. 点击涟漪动效
   - 涟漪颜色: 半透明白色
   - 涟漪形状: 圆形扩散
   - 涟漪范围: 从点击位置扩散
   - 涟漪时长: 300-400ms

### 任务5: 动效性能优化方案

**任务ID**: UID-3-TASK-005
**优先级**: P2 (中)
**任务描述**: 制定动效的性能优化方案

**设计要点**:
1. 动画优化
   - 使用CSS3动画代替JavaScript动画
   - 使用transform和opacity属性
   - 避免使用left/top属性
   - 使用will-change属性

2. 粒子优化
   - 限制粒子数量
   - 使用对象池复用粒子
   - 使用Canvas绘制粒子
   - 粒子生命周期管理

3. 动效分级
   - 低端设备: 简化动效，减少粒子
   - 中端设备: 标准动效
   - 高端设备: 完整动效，更多粒子

4. 性能监控
   - FPS监控
   - 动效性能分析
   - 性能阈值设置
   - 自动降级机制

## 四、设计规范要求

### 4.1 文档规范
- 所有设计文档使用Markdown格式

- 文档结构: 概述→设计要点→动效参数→验收标准
- 动效演示使用GIF或视频格式

### 4.2 动效规范
- 动效时长: 100-1000ms
- 缓动函数: ease-in-out / ease-out
- 动效频率: 避免过于频繁
- 动效强度: 符合二次元风格

### 4.3 性能规范
- FPS目标: 60fps
- 动效内存占用: < 10MB
- 粒子数量上限: 100个
- 同时播放动效上限: 10个

### 4.4 协作规范
- 与UI策划(UID-1/UID-2)协作，确保动效符合界面设计
- 与程序协作，确保动效可实现
- 与音效策划协作，确保动效与音效同步
- 与测试协作，确保动效性能良好

## 六、风险提示

### 6.1 性能风险
**风险描述**: 复杂动效影响游戏性能
**应对措施**: 动效分级，性能优化，自动降级

### 6.2 体验风险
**风险描述**: 动效过于频繁影响游戏体验
**应对措施**: 控制动效频率，提供关闭选项

### 6.3 兼容性风险
**风险描述**: 不同设备动效表现差异大
**应对措施**: 多设备测试，优化适配方案
