## 一、设计概述

### 1.1 设计目标
商店界面是Clicker Quest游戏中玩家购买道具的核心场所，界面设计直接影响玩家的购买决策和游戏经济体验。本设计旨在：
- 创造清晰易用的商店界面
- 设计有吸引力的道具卡片
- 确保购买流程顺畅自然
- 符合二次元动漫风格

### 1.2 设计原则
- **视觉层次清晰**: 重要信息突出显示
- **操作便捷**: 减少点击次数，优化购买流程
- **信息完整**: 道具信息展示全面但不冗余
- **风格统一**: 符合二次元动漫风格

        └─ 播放购买失败音效

## 五、滚动列表交互设计

### 5.1 滚动方式

#### 5.1.1 垂直滚动
- **滚动方向**: 垂直上下滚动
- **滚动方式**: 触摸滑动 / 鼠标滚轮
- **滚动速度**: 跟随手指/滚轮速度

#### 5.1.2 惯性滚动
- **惯性效果**: 松手后继续滚动
- **摩擦系数**: 0.95 (逐渐减速)
- **停止条件**: 速度 < 1px/s 或到达边界

#### 5.1.3 边界回弹
- **回弹效果**: 滚动到边界时回弹
- **回弹距离**: 最大 50px
- **回弹动画**: 弹性动画 (ease-out)
- **回弹时间**: 0.3s

### 5.2 滚动反馈

#### 5.2.1 滚动条显示
- **显示时机**: 滚动时显示，停止后 1s 淡出
- **滚动条宽度**: 6px
- **滚动条颜色**: rgba(255, 255, 255, 0.3)
- **滚动条圆角**: 3px
- **滚动条位置**: 右侧，距离边缘 5px

#### 5.2.2 滚动指示
- **指示方式**: 滚动条长度表示内容比例
- **滚动条长度**: 根据内容高度动态计算
  - 公式: (可视区域高度 / 总内容高度) * 可视区域高度

#### 5.2.3 滚动提示
- **顶部提示**: 
  - 触发条件: 滚动到顶部时
  - 提示内容: "下拉刷新" (可选功能)
  - 提示样式: 箭头图标 + 文字
  
- **底部提示**:
  - 触发条件: 滚动到底部时
  - 提示内容: "已经到底了~"
  - 提示样式: 文字 + 底部图标
  - 文字颜色: #AAAAAA
  - 字体大小: 14px

### 5.3 滚动优化

#### 5.3.1 虚拟列表
- **启用条件**: 道具数量 > 50
- **渲染策略**: 只渲染可视区域 + 缓冲区域的卡片
- **缓冲区域**: 上下各多渲染 3 张卡片
- **回收机制**: 滚出可视区域的卡片回收复用

#### 5.3.2 懒加载
- **加载策略**: 滚动时加载道具图标
- **加载时机**: 卡片进入可视区域前 200px
- **占位图**: 使用灰色方块作为占位图
- **加载动画**: 淡入效果 (0.3s)

#### 5.3.3 滚动性能优化
- **GPU 加速**: 使用 transform 而非 top/left
- **防抖处理**: 滚动事件防抖 (100ms)
- **节流处理**: 渲染更新节流 (16ms = 60fps)
- **避免重排**: 使用 absolute 定位卡片

## 七、动画规范

### 7.1 过渡动画

#### 7.1.1 标准过渡
- **持续时间**: 0.3s
- **缓动函数**: ease-in-out
- **应用场景**: 状态切换、悬停效果

#### 7.1.2 快速过渡
- **持续时间**: 0.2s
- **缓动函数**: ease-out
- **应用场景**: 按钮点击、卡片缩放

#### 7.1.3 慢速过渡
- **持续时间**: 0.5s
- **缓动函数**: ease-in-out
- **应用场景**: 页面切换、模态框显示

### 7.2 关键帧动画

#### 7.2.1 闪烁动画 (限时道具)
```css
@keyframes flash {
  0%, 100% { border-color: rgba(255, 100, 100, 0.8); }
  50% { border-color: rgba(255, 100, 100, 0.3); }
}
```
- **持续时间**: 1s
- **循环**: 无限循环

#### 7.2.2 淡入动画 (卡片加载)
```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```
- **持续时间**: 0.3s
- **缓动函数**: ease-in

#### 7.2.3 滑入动画 (Toast 提示)
```css
@keyframes slideIn {
  from { 
    transform: translateY(-100%);
    opacity: 0;
  }
  to { 
    transform: translateY(0);
    opacity: 1;
  }
}
```
- **持续时间**: 0.3s
- **缓动函数**: ease-out

### 7.3 性能优化
- **使用 transform**: 代替 top/left 进行位移
- **使用 opacity**: 代替 visibility 进行显示隐藏
- **硬件加速**: 使用 will-change 提示浏览器
- **减少重排**: 避免频繁修改布局属性

## 八、交互流程设计

### 8.1 商店打开流程
```
用户点击商店按钮
    ↓
显示加载动画 (0.5s)
    ↓
加载商店数据
    ↓
    ├─ 加载成功
    │   ├─ 显示商店界面
    │   ├─ 默认选中"升级"标签
    │   ├─ 显示升级类道具列表
    │   └─ 播放商店打开音效
    │
    └─ 加载失败
        ├─ 显示错误提示
        └─ 提供重试按钮
```

### 8.2 标签切换流程
```
用户点击标签 (升级/道具/特殊)
    ↓
标签切换动画 (0.3s)
    ↓
清空当前列表
    ↓
加载对应分类道具
    ↓
显示新道具列表 (淡入动画)
    ↓
播放标签切换音效
```

### 8.3 购买流程
```
用户点击"购买"按钮
    ↓
显示购买确认弹窗 (可选)
    ↓
    ├─ 用户确认购买
    │   ├─ 扣除金币
    │   ├─ 发放道具
    │   ├─ 更新界面状态
    │   ├─ 显示成功提示
    │   └─ 播放成功音效
    │
    └─ 用户取消购买
        └─ 关闭弹窗
```
