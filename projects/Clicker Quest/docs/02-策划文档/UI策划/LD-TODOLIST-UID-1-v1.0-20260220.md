## 一、任务概览

作为UI策划-主界面(UID-1)，你负责设计Clicker Quest游戏的主界面和成就界面。主界面是玩家最常看到的界面，直接影响游戏的第一印象和长期体验。

**核心目标**:
- 设计清晰美观的主界面布局
- 创造有吸引力的点击按钮设计
- 确保界面响应式适配

**优先级**: P0 (核心功能，必须优先完成)

## 三、设计任务清单

### 任务1: 主界面布局设计

**任务ID**: UID-1-TASK-001
**优先级**: P0 (最高)
**任务描述**: 设计主界面的整体布局和元素分布

**设计要点**:
1. 界面布局结构
   ```
   +----------------------------------+
   |  [金币] 1000  [DPS] 10/s        |  <- 顶部状态栏
   +----------------------------------+
   |                                  |
   |         [点击按钮区域]           |  <- 中央点击区域
   |       (二次元角色/按钮)          |
   |                                  |
   +----------------------------------+
   | [主页] [商店] [成就] [排行]      |  <- 底部导航栏
   +----------------------------------+
   ```

2. 顶部状态栏
   - 金币显示区域: 图标 + 数量
   - DPS显示区域: 图标 + 数量
   - 状态栏高度: 60px
   - 状态栏背景: 半透明渐变

3. 中央点击区域
   - 点击按钮尺寸: 200x200px (可调整)
   - 点击按钮位置: 屏幕中央
   - 点击按钮样式: 二次元风格
   - 背景装饰: 动漫风格背景

4. 底部导航栏
   - 导航按钮数量: 4个
   - 导航按钮尺寸: 80x60px
   - 导航栏高度: 80px
   - 导航栏背景: 半透明渐变

**输出交付**:
- [主界面布局设计文档](../../02-策划文档/UI策划/主界面布局设计.md)
- 主界面布局图(图片格式)

**验收标准**:
- [ ] 界面布局合理，符合用户习惯
- [ ] 各区域尺寸明确，便于实现
- [ ] 布局图清晰，标注完整
- [ ] 文档完整，包含所有设计要点

### 任务2: 点击按钮设计

**任务ID**: UID-1-TASK-002
**优先级**: P0 (最高)
**任务描述**: 设计主界面的点击按钮样式和交互

**设计要点**:
1. 按钮样式
   - 按钮形状: 圆形/圆角矩形
   - 按钮尺寸: 200x200px
   - 按钮颜色: 符合二次元风格
   - 按钮图标: 可使用角色头像或图标

2. 按钮状态
   - 默认状态: 正常显示
   - 悬停状态: 轻微放大/发光效果
   - 点击状态: 缩小/震动效果
   - 禁用状态: 灰色显示

3. 按钮反馈
   - 点击缩放: 缩小至90%后恢复
   - 点击音效: 配合音效设计
   - 点击特效: 配合动效设计

**输出交付**:
- [点击按钮设计文档](../../02-策划文档/UI策划/点击按钮设计.md)
- 按钮设计稿(图片格式)

**验收标准**:
- [ ] 按钮样式符合二次元风格
- [ ] 按钮状态完整，交互流畅
- [ ] 按钮反馈设计合理
- [ ] 文档完整，包含所有设计要点

### 任务4: UI响应式适配方案

**任务ID**: UID-1-TASK-004
**优先级**: P1 (高)
**任务描述**: 设计多设备适配的UI方案

**设计要点**:
1. 设备适配
   - PC端: 1920x1080, 1366x768
   - 平板端: 1024x768, 768x1024
   - 手机端: 375x667, 414x896

2. 适配规则
   - 点击按钮: 根据屏幕尺寸缩放
   - 状态栏: 固定高度，宽度100%
   - 导航栏: 固定高度，宽度100%
   - 字体大小: 根据屏幕尺寸调整

3. 布局调整
   - PC端: 居中显示，最大宽度限制
   - 平板端: 自适应宽度
   - 手机端: 全屏显示，简化布局

**输出交付**:

### 任务5: UI交互规范制定

**任务ID**: UID-1-TASK-005
**优先级**: P2 (中)
**任务描述**: 制定UI交互的统一规范

**设计要点**:
1. 交互反馈规范
   - 点击反馈: 缩放/震动/发光
   - 悬停反馈: 放大/发光/提示
   - 长按反馈: 震动/菜单弹出
   - 滑动反馈: 惯性滚动/边界回弹

2. 动画规范
   - 动画时长: 100-300ms
   - 动画曲线: ease-in-out
   - 动画类型: 缩放/位移/透明度
   - 动画触发: 点击/悬停/自动

3. 提示规范
   - 成功提示: 绿色，2秒自动消失
   - 失败提示: 红色，3秒自动消失
   - 信息提示: 蓝色，2秒自动消失
   - 确认提示: 弹窗，需要用户确认

**输出交付**:
- [UI交互规范文档](../../02-策划文档/UI策划/UI交互规范.md)
- 交互规范示例(图片/GIF格式)

**验收标准**:
- [ ] 交互反馈规范完整
- [ ] 动画规范清晰
- [ ] 提示规范合理
- [ ] 文档完整，包含所有设计要点

## 四、设计规范要求

### 4.1 文档规范
- 所有设计文档使用Markdown格式
- 文档命名格式: `[模块名称]设计.md`
- 文档结构: 概述→设计要点→设计稿→验收标准
- 设计稿使用图片格式，标注清晰

### 4.2 设计规范
- 配色方案: 符合二次元动漫风格
- 字体规范: 主字体、辅助字体、字号范围
- 图标规范: 图标风格、尺寸、颜色
- 间距规范: 元素间距、边距、内边距

### 4.3 命名规范
- 元素ID命名: `[区域]_[元素]_[功能]` (如: top_bar_gold_display)
- 类名命名: 使用BEM命名法
- 图片命名: `[模块]_[元素]_[状态].[格式]` (如: btn_click_default.png)

### 4.4 协作规范
- 与动效策划(UID-3)协作，确保动效设计合理
- 与程序协作，确保设计可实现
- 与美术协作，确保美术资源符合设计要求
- 与测试协作，确保UI交互体验良好
