## 一、设计概述

### 1.1 设计目标
- 打造清晰直观的主界面布局，确保玩家快速理解游戏核心玩法
- 设计具有二次元动漫风格的视觉元素，提升游戏吸引力
- 确保界面响应式适配，支持多设备访问
- 提供流畅的交互体验，增强玩家沉浸感

### 1.2 设计风格
- **美术风格**: 二次元动漫风格
- **配色方案**: 明亮活泼，以蓝紫渐变为主色调
- **视觉层次**: 清晰的信息层级，重要信息突出显示
- **交互反馈**: 丰富的动效和音效反馈

### 1.3 目标设备
- PC端: 1920x1080, 1366x768
- 平板端: 1024x768, 768x1024
- 手机端: 375x667, 414x896

```css

/* 恢复时 */
transform: scale(1);
transition: transform 100ms ease-in;
```

**呼吸动画**:
```css
@keyframes breathe {
  0%, 100% { transform: scale(1); box-shadow: 0 8px 32px rgba(99, 102, 241, 0.4); }
  50% { transform: scale(1.02); box-shadow: 0 12px 40px rgba(99, 102, 241, 0.6); }
}
animation: breathe 2s ease-in-out infinite;
```

## 五、交互说明

### 5.1 主界面交互

#### 5.1.1 点击按钮交互

**点击流程**:
```
玩家点击按钮
    ↓
按钮缩小至 90% (100ms)
    ↓
播放点击音效
    ↓
计算金币获取 (普通/暴击)
    ↓
显示金币飘字
    ↓
按钮恢复至 100% (100ms)
    ↓
更新金币显示 (数字滚动动画)
```

**暴击交互**:
```
触发暴击
    ↓
按钮变为金色边框
    ↓
播放暴击特效
    ↓
屏幕轻微震动
    ↓
显示暴击飘字 (更大、金色)
    ↓
播放暴击音效
    ↓
恢复默认状态
```

#### 5.1.2 金币飘字交互

**飘字动画**:
```css
@keyframes coinFloat {
  0% {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
  100% {
    opacity: 0;
    transform: translateY(-80px) scale(1.2);
  }
}
animation: coinFloat 1s ease-out forwards;
```

**飘字属性**:
| 属性 | 普通点击 | 暴击 |
|------|---------|------|
| 字号 | 24px | 36px |
| 颜色 | #FFD700 | #FF6B00 |
| 动画时长 | 1s | 1.5s |
| 缩放 | 1.2x | 1.5x |

#### 5.1.3 导航栏交互

**切换流程**:
```
点击导航按钮
    ↓
当前界面淡出 (200ms)
    ↓
新界面淡入 (200ms)
    ↓
更新导航按钮状态
```

**导航按钮状态**:
| 状态 | 视觉效果 |
|------|---------|
| 默认 | 半透明白色，无背景 |
| 悬停 | 白色，轻微放大 |
| 激活 | 紫色，底部指示条 |
| 禁用 | 灰色，不可点击 |

### 5.2 成就界面交互

#### 5.2.1 成就卡片交互

**悬停效果**:
```css
/* 悬停时 */
transform: translateY(-2px);
box-shadow: 0 8px 24px rgba(99, 102, 241, 0.3);
border-color: rgba(139, 92, 246, 0.5);
transition: all 200ms ease-out;
```

**点击领取**:
```
点击"领取"按钮
    ↓
按钮变为加载状态
    ↓
播放领取动画 (金币飞向顶部)
    ↓
更新金币数量
    ↓
按钮变为"已领取"状态
    ↓
播放成功提示
```

#### 5.2.2 筛选功能交互

**筛选流程**:
```
点击筛选按钮
    ↓
显示筛选弹窗 (淡入动画)
    ↓
选择筛选条件
    ↓
应用筛选 (卡片重新排列)
    ↓
关闭筛选弹窗
```

**筛选动画**:
```css
/* 卡片重新排列 */
.achievement-card {
  transition: all 300ms ease-out;

/* 隐藏的卡片 */

  transform: scale(0.8);
  pointer-events: none;
}
```

- 边界回弹效果
- 滚动时隐藏返回顶部按钮
