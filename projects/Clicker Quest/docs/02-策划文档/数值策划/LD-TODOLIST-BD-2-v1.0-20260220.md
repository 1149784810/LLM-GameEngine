## 一、任务概览

作为数值策划-道具价格(BD-2)，你负责设计Clicker Quest游戏的道具定价系统。道具价格直接影响游戏经济平衡和玩家购买决策，是游戏商业化的重要组成部分。

**核心目标**:

## 三、设计任务清单

### 任务1: 道具价格曲线设计

**任务ID**: BD-2-TASK-001
**优先级**: P0 (最高)
**任务描述**: 设计各类道具的价格增长曲线

**设计要点**:
1. 自动点击器价格曲线
   - 初级自动点击器: 100金币
   - 中级自动点击器: 500金币
   - 高级自动点击器: 2,000金币
   - 顶级自动点击器: 10,000金币
   - 价格增长公式: price = base_price × (1.5 ^ level)

2. 增益道具价格曲线
   - 金币翻倍(30秒): 1,000金币
   - 金币翻倍(60秒): 2,500金币
   - 金币翻倍(120秒): 5,000金币
   - 价格增长公式: price = base_price × duration_factor

3. 特殊道具价格曲线
   - 幸运药水: 500金币
   - 时间加速: 1,000金币
   - 离线收益提升: 2,000金币
   - 价格增长公式: price = base_price × effect_factor

4. 价格上限设置
   - 单个道具价格上限: 1e+12金币
   - 防止价格过高影响购买

**输出交付**:
- [道具价格曲线设计文档](../../02-策划文档/数值策划/道具价格曲线设计.md)
- 价格曲线图表(Excel/图片格式)
- 价格数值表(Excel/CSV格式)

**验收标准**:
- [ ] 价格曲线设计合理
- [ ] 价格增长公式明确
- [ ] 价格上限设置合理

### 任务2: 道具性价比计算

**任务ID**: BD-2-TASK-002
**优先级**: P1 (高)
**任务描述**: 计算各类道具的性价比，确保平衡

**设计要点**:
1. 性价比定义
   - 性价比 = 道具效果 / 道具价格
   - 效果量化: 金币产出、时间节省等
   - 统一单位: 金币/秒

2. 自动点击器性价比
   - 初级: 0.01金币/秒/金币
   - 中级: 0.01金币/秒/金币
   - 高级: 0.0125金币/秒/金币
   - 顶级: 0.01金币/秒/金币
   - 性价比相近，略有提升

3. 增益道具性价比
   - 金币翻倍(30秒): 0.03金币/秒/金币
   - 金币翻倍(60秒): 0.024金币/秒/金币
   - 金币翻倍(120秒): 0.02金币/秒/金币
   - 时长越长，性价比越低

4. 性价比平衡原则
   - 基础道具: 高性价比，鼓励购买
   - 高级道具: 中性价比，长期目标
   - 特殊道具: 低性价比，稀有奖励

**输出交付**:
- [道具性价比计算文档](../../02-策划文档/数值策划/道具性价比计算.md)
- 性价比对比表(Excel/CSV格式)

**验收标准**:
- [ ] 性价比定义清晰
- [ ] 性价比计算准确
- [ ] 性价比平衡合理
- [ ] 文档完整

1. 价格调整触发条件

   - 游戏经济失衡

2. 价格调整原则

   - 玩家补偿: 降价时补偿已购买玩家
   - 提前公告: 提前通知玩家

3. 价格调整流程
   - 数据监控 → 问题分析 → 方案设计 → 测试验证 → 公告通知 → 上线实施

## 四、设计规范要求

### 4.1 文档规范
- 所有设计文档使用Markdown格式
- 文档命名格式: `[模块名称]设计.md`
- 文档结构: 概述→设计要点→数值表→验收标准
- 数值表使用Excel或CSV格式

### 4.2 数值规范
- 所有价格使用整数
- 大数值使用科学计数法(如: 1e+12)
- 百分比使用整数表示(如: 80表示80%)
- 价格精度统一

### 4.3 命名规范
- 道具ID: `item_[类型]_[序号]`
- 价格ID: `price_[道具ID]`
- 折扣ID: `discount_[序号]`

### 4.4 协作规范
- 与道具策划(SD-3)协作，确保价格符合道具价值
- 与商店策划(SD-2)协作，确保价格展示合理
- 与经济曲线策划(BD-1)协作，确保价格符合经济曲线
- 与程序协作，确保价格可实现
