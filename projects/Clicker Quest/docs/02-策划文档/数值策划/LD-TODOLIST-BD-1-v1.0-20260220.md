## 一、任务概览

作为数值策划-经济曲线(BD-1)，你负责设计Clicker Quest游戏的经济系统和数值曲线。经济曲线是游戏平衡的核心，直接影响玩家的成长节奏和游戏体验。

**核心目标**:

**优先级**: P1 (重要功能，优先完成)

## 三、设计任务清单

### 任务1: 金币产出曲线设计

**任务ID**: BD-1-TASK-001
**优先级**: P0 (最高)
**任务描述**: 设计金币产出的增长曲线

**设计要点**:
1. 前期曲线(0-10分钟)
   - 目标: 快速成长，建立成就感
   - 点击产出: 1-5金币/次
   - 自动产出: 0-10金币/秒
   - 总产出: 指数增长(快速)

2. 中期曲线(10-60分钟)
   - 目标: 稳定成长，解锁新内容
   - 点击产出: 5-50金币/次
   - 自动产出: 10-100金币/秒
   - 总产出: 线性增长(稳定)

3. 后期曲线(1小时+)
   - 目标: 缓慢成长，追求极限
   - 点击产出: 50-500金币/次
   - 自动产出: 100-1000金币/秒
   - 总产出: 对数增长(缓慢)

4. 曲线公式
   - 前期: y = a * x^2 (指数增长)
   - 中期: y = a * x + b (线性增长)
   - 后期: y = a * log(x) + b (对数增长)

- 产出曲线图表(Excel/图片格式)
- 产出数值表(Excel/CSV格式)

**验收标准**:
- [ ] 产出曲线设计合理
- [ ] 前中后期节奏清晰

### 任务2: 游戏节奏曲线设计

**任务ID**: BD-1-TASK-002
**优先级**: P0 (最高)
**任务描述**: 设计游戏整体的节奏曲线

**设计要点**:
1. 新手引导阶段(0-5分钟)
   - 目标: 熟悉操作，建立兴趣
   - 关键节点: 第一次点击、第一次购买
   - 奖励频率: 高频小奖励
   - 解锁内容: 基础功能

2. 快速成长阶段(5-30分钟)
   - 目标: 快速成长，建立成就感
   - 关键节点: 第一个自动点击器、第一个暴击
   - 奖励频率: 中频中奖励
   - 解锁内容: 核心道具

3. 稳定成长阶段(30分钟-2小时)
   - 目标: 稳定成长，探索深度
   - 关键节点: 第一个成就、第一个限时道具
   - 奖励频率: 低频大奖励
   - 解锁内容: 高级道具

4. 长期运营阶段(2小时+)
   - 目标: 长期留存，追求极限
   - 关键节点: 全成就、排行榜前列

### 任务3: 数值平衡方案制定

**任务ID**: BD-1-TASK-003
**优先级**: P1 (高)
**任务描述**: 制定游戏整体的数值平衡方案

**设计要点**:
1. 产出消耗平衡
   - 金币产出: 点击 + 自动 + 成就
   - 金币消耗: 购买道具 + 升级
   - 平衡目标: 产出略大于消耗

2. 道具性价比平衡
   - 基础道具: 高性价比，快速购买
   - 高级道具: 中性价比，长期目标
   - 特殊道具: 低性价比，稀有奖励

3. 时间价值平衡
   - 在线收益: 100%
   - 离线收益: 50%(可通过道具提升)
   - 平衡目标: 鼓励在线，但不强制

4. 数值上限设置
   - 金币上限: 1e+308 (JavaScript最大值)
   - DPS上限: 1e+15
   - 道具数量上限: 1000
   - 防止数值溢出

**输出交付**:
- [数值平衡方案文档](../../02-策划文档/数值策划/数值平衡方案.md)
- 平衡数值表(Excel/CSV格式)

**验收标准**:
- [ ] 平衡方案设计合理
- [ ] 产出消耗平衡
- [ ] 道具性价比合理
- [ ] 数值上限设置合理

### 任务4: 离线收益公式设计

**任务ID**: BD-1-TASK-004
**优先级**: P1 (高)
**任务描述**: 设计离线收益的计算公式

**设计要点**:
1. 基础公式
   - 离线收益 = DPS × 离线时长 × 离线比例
   - 离线比例: 基础50%
   - 离线时长上限: 24小时

2. 离线比例提升
   - 基础比例: 50%
   - 道具提升: 每个道具+10%，最高+50%
   - 最高比例: 100%

3. 离线时长限制
   - 最短时长: 5分钟(低于5分钟不计)
   - 最长时长: 24小时(超过24小时按24小时计算)
   - 时长分段: 0-6小时(100%)、6-12小时(80%)、12-24小时(60%)

4. 离线收益展示
   - 显示离线时长
   - 显示离线收益
   - 显示离线比例
   - 领取动画

### 任务5: 数值验证和调整

**任务ID**: BD-1-TASK-005
**优先级**: P2 (中)
**任务描述**: 建立数值验证和调整机制

**设计要点**:
1. 数值验证方法
   - 模拟测试: 模拟不同时长的游戏过程
   - 数据分析: 分析玩家数据，验证数值合理性
   - A/B测试: 对比不同数值方案的效果

2. 数值调整原则
   - 小幅调整: 每次调整幅度不超过20%
   - 数据驱动: 基于数据调整，避免主观臆断
   - 玩家反馈: 收集玩家反馈，作为调整依据

3. 数值调整流程
   - 数据收集 → 问题分析 → 方案设计 → 测试验证 → 上线实施

4. 应急调整预案
   - 数值膨胀过快: 提高价格、降低产出
   - 数值增长过慢: 降低价格、提高产出
   - 道具性价比失衡: 调整价格或效果

**输出交付**:
- [数值验证和调整文档](../../02-策划文档/数值策划/数值验证和调整.md)
- 数值验证表(Excel/CSV格式)

## 六、风险提示

### 6.1 数值膨胀风险
**风险描述**: 后期数值过大，导致显示和计算问题
**应对措施**: 设置数值上限，引入衰减机制

### 6.2 平衡性风险
**风险描述**: 数值不平衡导致游戏体验差
**应对措施**: 多轮测试调整，收集玩家反馈

### 6.3 玩家流失风险
**风险描述**: 数值增长过慢导致玩家流失
**应对措施**: 优化数值曲线，增加奖励频率
