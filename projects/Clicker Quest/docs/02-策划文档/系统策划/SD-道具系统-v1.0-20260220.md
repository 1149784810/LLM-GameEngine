## 一、系统概述

### 1.1 系统定位

道具系统是Clicker Quest游戏的核心成长系统之一,为玩家提供多样化的获取金币途径和策略选择。通过不同类型道具的组合使用,玩家可以定制自己的成长路径,增加游戏的深度和可玩性。

### 1.2 设计目标

- **多样性**: 提供多种类型的道具,满足不同玩家的游戏风格
- **策略性**: 道具组合使用产生策略深度,鼓励玩家思考最优配置
- **平衡性**: 道具效果平衡,不会破坏游戏经济系统
- **成长感**: 道具获取和使用带来明显的成长反馈

### 1.3 系统关联

| 关联系统 | 关联方式 | 说明 |
|---------|---------|------|
| 点击系统 | 道具影响点击效果 | 金币翻倍道具影响点击获取金币 |
| 金币系统 | 道具消耗金币 | 购买道具需要消耗金币 |
| 商店系统 | 道具购买渠道 | 商店出售各类道具 |
| 升级系统 | 道具提供加成 | 部分道具提升升级效果 |
| 成就系统 | 道具获取途径 | 完成成就奖励道具 |

## 二、道具类型定义

### 2.1 道具分类体系

道具系统分为四大类型,每种类型有不同的作用机制和使用规则:

```
道具系统
├── 自动点击器类 (Auto Clicker)
│   ├── 初级自动点击器
│   ├── 中级自动点击器
│   ├── 高级自动点击器
│   └── 顶级自动点击器
├── 增益类 (Buff)
│   ├── 金币翻倍道具
│   ├── 幸运药水
│   └── 时间加速
├── 消耗类 (Consumable)
│   ├── 金币宝箱
│   ├── 幸运符
│   └── 时间胶囊
└── 永久类 (Permanent)
    ├── 永久金币加成
    ├── 永久暴击加成
    └── 永久DPS加成
```

### 2.2 道具属性定义

#### 2.2.1 基础属性

所有道具共有的基础属性:

| 属性名 | 属性类型 | 说明 | 示例 |
|-------|---------|------|------|
| itemId | String | 道具唯一标识符 | item_auto_001 |
| itemName | String | 道具显示名称 | 初级自动点击器 |
| itemDescription | String | 道具效果说明 | 每秒自动产出1金币 |
| itemIcon | String | 道具图标资源ID | icon_auto_clicker_01 |
| itemRarity | Enum | 道具稀有度 | COMMON/RARE/EPIC/LEGENDARY |
| itemType | Enum | 道具类型 | AUTO/BUFF/CONSUMABLE/PERMANENT |
| maxStack | Integer | 最大堆叠数量 | 99 |
| sellPrice | Integer | 出售价格(金币) | 100 |

#### 2.2.2 效果属性

道具效果相关属性:

| 属性名 | 属性类型 | 说明 | 示例 |
|-------|---------|------|------|
| effectType | Enum | 效果类型 | GOLD_MULTIPLIER/CRIT_RATE/DPS_BOOST |

| effectScope | Enum | 效果范围 | CLICK/AUTO_CLICKER/ALL |

#### 2.2.3 获取属性

| 属性名 | 属性类型 | 说明 | 示例 |
|-------|---------|------|------|
| buyPrice | Integer | 购买价格(金币) | 1000 |

| 道具ID | 道具名称 | 稀有度 | 基础产出 | 购买价格 | 离线时长 | 性价比 |
|--------|---------|--------|---------|---------|---------|--------|
| item_auto_001 | 初级自动点击器 | COMMON | 1金币/秒 | 100金币 | 8小时 | 0.01 |
| item_auto_002 | 中级自动点击器 | RARE | 5金币/秒 | 500金币 | 12小时 | 0.01 |

**设计说明**:
- 性价比 = 基础产出 / 购买价格
- 初期道具性价比一致,后期略微降低防止数值膨胀
- 离线时长随稀有度增加,鼓励获取高级道具

### 3.3 离线收益机制

#### 3.3.1 离线收益计算

```
离线收益 = Σ(自动点击器基础产出 × 数量) × 离线时间 × 离线效率
```

**参数说明**:
- 离线时间: 实际离线时长(秒),不超过最大离线时长
- 离线效率: 默认为0.5(50%),可通过道具提升

#### 3.3.2 离线收益限制

| 限制项 | 限制规则 | 说明 |
|-------|---------|------|
| 最大离线时长 | 根据自动点击器类型 | 初级8小时,顶级24小时 |
| 离线效率 | 基础50% | 可通过道具提升至100% |
| 收益上限 | 单次最多获得24小时收益 | 防止长期挂机获益过多 |

#### 3.3.3 离线收益展示

玩家上线时显示离线收益弹窗:
- 显示离线时长
- 显示获得的金币总数
- 显示各自动点击器的贡献
- 提供"双倍领取"按钮(观看广告)

**效果机制**:
- 永久提升所有自动点击器效率20%

## 七、叠加规则设计

### 7.1 叠加类型定义

| 叠加类型 | 英文标识 | 说明 | 示例 |
|---------|---------|------|------|
| 可叠加 | STACKABLE | 效果累加,无上限 | 幸运药水 |
| 刷新叠加 | REFRESH | 效果不累加,刷新时间 | 金币翻倍 |
| 上限叠加 | CAP | 效果累加,有上限 | 暴击率(上限50%) |
| 不可叠加 | NON_STACKABLE | 效果不累加,不刷新 | 永久加成 |

### 7.2 叠加规则详解

#### 7.2.1 金币翻倍道具叠加

**叠加类型**: 刷新叠加(REFRESH)

**规则说明**:
- 同类型道具不叠加效果
- 使用新道具时刷新持续时间
- 不同倍率道具取最高倍率

**示例**:
```
场景: 已激活小型金币翻倍(剩余20秒),使用中型金币翻倍
结果: 金币翻倍效果持续60秒(中型持续时间)
```

#### 7.2.2 幸运药水叠加

**叠加类型**: 上限叠加(CAP)

**规则说明**:
- 同类型道具效果累加
- 暴击率上限为50%
- 超过上限部分无效

**示例**:
```
场景: 基础暴击率5%,使用小型幸运药水(+10%),再使用中型幸运药水(+20%)
计算: 5% + 10% + 20% = 35%
结果: 实际暴击率35%
```

#### 7.2.3 时间加速叠加

**叠加类型**: 刷新叠加(REFRESH)

**规则说明**:
- 同类型道具不叠加倍率
- 使用新道具时刷新持续时间
- 不同倍率道具取最高倍率

**示例**:
```
场景: 已激活小型时间加速(2倍,剩余30秒),使用中型时间加速(5倍)
结果: 时间加速效果5倍,持续120秒(中型持续时间)
```

#### 7.2.4 自动点击器叠加

**叠加类型**: 可叠加(STACKABLE)

**规则说明**:
- 多个自动点击器产出累加
- 不同等级自动点击器独立计算
- 无上限限制

**示例**:
```
场景: 拥有3个初级自动点击器,2个中级自动点击器
计算: (1 × 3) + (5 × 2) = 13金币/秒
结果: 实际DPS = 13金币/秒
```

### 7.3 叠加规则表

| 道具类型 | 叠加类型 | 叠加上限 | 说明 |
|---------|---------|---------|------|
| 金币翻倍 | REFRESH | - | 刷新时间,取最高倍率 |
| 幸运药水 | CAP | 50%暴击率 | 效果累加,有上限 |
| 时间加速 | REFRESH | - | 刷新时间,取最高倍率 |
| 自动点击器 | STACKABLE | - | 产出累加,无上限 |
| 金币宝箱 | NON_STACKABLE | - | 独立使用,不叠加 |
| 幸运符 | NON_STACKABLE | - | 独立使用,不叠加 |
| 永久加成 | STACKABLE | 有购买上限 | 效果累加,有上限 |

### 7.4 叠加显示设计

#### 7.4.1 当前叠加状态

在游戏主界面显示当前激活的增益效果:
- 增益图标

- 剩余时间

#### 7.4.2 叠加效果预览

## 九、数值平衡设计

### 9.1 道具性价比分析

#### 9.1.1 自动点击器性价比

| 道具 | 购买价格 | 基础产出 | 回本时间 | 长期收益 |
|------|---------|---------|---------|---------|
| 初级 | 100金币 | 1金币/秒 | 100秒 | 优秀 |
| 中级 | 500金币 | 5金币/秒 | 100秒 | 优秀 |
| 高级 | 2500金币 | 25金币/秒 | 100秒 | 优秀 |
| 顶级 | 12500金币 | 100金币/秒 | 125秒 | 良好 |

**设计说明**:
- 初期道具回本时间一致,保证公平性
- 后期道具回本时间略长,防止数值膨胀
- 鼓励玩家持续投资自动点击器

#### 9.1.2 增益道具性价比

**金币翻倍道具**:
- 小型: 30秒 / 500金币 = 0.06秒/金币
- 中型: 60秒 / 900金币 = 0.067秒/金币
- 大型: 120秒 / 1600金币 = 0.075秒/金币

**使用建议**:
- DPS > 100金币/秒时,使用金币翻倍道具划算
- 配合高DPS时段使用,最大化收益

**幸运药水**:
- 小型: 60秒 × 10% = 6秒等效暴击时间
- 中型: 120秒 × 20% = 24秒等效暴击时间
- 大型: 300秒 × 50% = 150秒等效暴击时间

**使用建议**:
- 暴击倍率越高,幸运药水价值越大
- 配合高暴击倍率使用

### 9.2 数值增长曲线

#### 9.2.1 前期数值(0-10分钟)

**目标**:
- 让玩家快速体验道具系统
- 第一笔道具购买在2分钟内
- 道具效果明显,带来成就感

**数值设计**:
- 初级自动点击器: 100金币(2分钟可购买)
- 小型金币翻倍: 500金币(5分钟可购买)
- 小型幸运药水: 800金币(8分钟可购买)

#### 9.2.2 中期数值(10-60分钟)

**目标**:
- 道具组合使用,增加策略性
- 数值增长稳定,不会过快
- 解锁更多道具类型

**数值设计**:
- 中级自动点击器: 500金币
- 中型金币翻倍: 900金币
- 时间加速道具: 1000-2500金币

#### 9.2.3 后期数值(1小时+)

**目标**:
- 追求极限数值
- 永久道具成为目标
- 数值增长放缓,防止膨胀

**数值设计**:
- 顶级自动点击器: 12500金币
- 永久加成道具: 30000-100000金币
- 传说道具: 需要长时间积累

### 9.3 平衡性检查

#### 9.3.1 数值上限检查

| 数值类型 | 设计上限 | 检查结果 |
|---------|---------|---------|
| 暴击率 | 50% | 幸运药水叠加不会超过上限 |
| 金币倍率 | 10倍 | 金币翻倍+永久加成不超过上限 |
| DPS倍率 | 100倍 | 时间加速+永久加成不超过上限 |
| 离线时长 | 24小时 | 顶级自动点击器离线时长合理 |

#### 9.3.2 经济平衡检查

**金币流入**:
- 点击获取: 基础来源
- 自动点击器: 主要来源
- 道具奖励: 辅助来源

**金币流出**:
- 购买道具: 主要消耗
- 购买升级: 主要消耗
- 其他消耗: 次要消耗

**平衡目标**:
- 金币流入略大于流出,保证成长感
- 道具价格与收益匹配,不会过贵或过便宜

## 十二、风险提示与应对
