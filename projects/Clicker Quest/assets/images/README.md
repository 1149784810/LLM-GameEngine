# 图片资源目录

此目录用于存放游戏图片资源。

## 目录结构

```
images/
├── icons/           # 图标资源
│   ├── coin.png     # 金币图标
│   ├── settings.png # 设置图标
│   └── ...
├── items/           # 道具图标
│   ├── auto_001.png # 自动点击器图标
│   └── ...
├── achievements/    # 成就图标
│   └── ...
└── ui/              # UI元素
    └── ...
```

## 图片规范

- 图标尺寸: 32x32, 48x48, 64x64
- 格式: PNG (支持透明)
- 命名: 小写字母+下划线
