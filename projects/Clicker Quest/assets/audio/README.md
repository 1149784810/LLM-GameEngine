# 音频资源目录

此目录用于存放游戏音频资源。

## 目录结构

```
audio/
├── sfx/             # 音效
│   ├── click.mp3    # 点击音效
│   ├── crit_small.mp3  # 小暴击音效
│   ├── crit_medium.mp3 # 中暴击音效
│   ├── crit_large.mp3  # 大暴击音效
│   ├── buy.mp3      # 购买音效
│   └── ...
└── music/           # 背景音乐
    └── bgm.mp3      # 主界面背景音乐
```

## 音频规范

- 格式: MP3
- 音效时长: < 2秒
- 背景音乐: 循环播放
