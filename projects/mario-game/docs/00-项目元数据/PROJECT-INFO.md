## 项目描述

基于经典超级马里奥1-1关卡设计的2D横版卷轴平台跳跃游戏，使用HTML5 Canvas + JavaScript技术实现，支持Web浏览器运行。

## 核心特性

- 经典马里奥玩法：移动、跳跃、踩敌人、顶砖块
- 道具系统：超级蘑菇、火焰花、星星
- 敌人系统：栗子怪、乌龟怪
- 关卡系统：经典1-1关卡设计
- 金币收集系统
- 终点旗帜通关
