## 一、项目概述

### 1.1 游戏类型
2D横版卷轴平台跳跃游戏

### 1.2 核心玩法
玩家控制马里奥角色，通过移动和跳跃躲避障碍、消灭敌人、收集金币，最终到达终点旗帜完成关卡。

### 1.3 目标平台
Web浏览器 (PC端)

## 二、场景设计

### 2.1 关卡列表

| 关卡ID | 关卡名称 | 主题 | 长度 |
|--------|---------|------|------|
| Level-1-1 | 草原关卡 | 草地/蓝天 | 中等 (~3400像素) |

### 2.2 关卡详细设计 - Level-1-1

#### 场景参数
- **场景尺寸**: 3400 x 480 像素
- **视口尺寸**: 800 x 480 像素
- **网格单元**: 16 x 16 像素
- **滚动方式**: 横向卷轴，向右推进

#### 场景元素
| 元素类型 | 数量 | 说明 |
|---------|------|------|
| 地面砖块 | ~200块 | 可站立平台 |
| 问号砖块 | 7个 | 可顶出道具 |
| 普通砖块 | ~50块 | 可被大马里奥破坏 |
| 隐藏砖块 | 2个 | 隐藏金币/道具 |
| 水管 | 4个 | 装饰性障碍 |
| 深渊 | 3处 | 掉落即死 |
| 终点旗帜 | 1个 | 通关目标 |

#### 关卡分段
1. **起始区** (0-400px): 平坦地面，教学区域
2. **问号砖块区** (400-800px): 第一个问号砖块，蘑菇道具
3. **敌人区** (800-1600px): 栗子怪巡逻，需要跳跃躲避
4. **砖块迷宫区** (1600-2400px): 多层砖块，隐藏道具
5. **水管区** (2400-3000px): 水管障碍，乌龟怪
6. **终点区** (3000-3400px): 终点旗帜，通关

## 三、角色设计

### 3.1 玩家角色 - 马里奥

#### 状态系统
| 状态 | 说明 | 血量 |
|------|------|------|
| 小马里奥 | 初始状态 | 1 (一碰即死) |
| 大马里奥 | 吃蘑菇后 | 2 (被碰变回小马里奥) |
| 火焰马里奥 | 吃火焰花后 | 2 (可发射火球) |
| 无敌马里奥 | 吃星星后 | 无敌 (限时) |

#### 移动参数
| 参数 | 小马里奥 | 大马里奥 | 单位 |
|------|---------|---------|------|
| 移动速度 | 120 | 120 | 像素/秒 |
| 奔跑速度 | 200 | 200 | 像素/秒 |
| 跳跃高度 | 96 | 96 | 像素 |
| 大跳高度 | 128 | 128 | 像素 |
| 重力加速度 | 800 | 800 | 像素/秒² |
| 角色尺寸 | 16x16 | 16x32 | 像素 |

#### 操作方式
| 按键 | 功能 |
|------|------|
| ← / A | 向左移动 |
| → / D | 向右移动 |
| ↑ / W / Space | 跳跃 |
| Shift | 奔跑 (加速) |
| X / J | 发射火球 (火焰马里奥) |

## 四、敌人设计

### 4.1 栗子怪 (Goomba)

| 属性 | 值 |
|------|-----|
| 尺寸 | 16x16 像素 |
| 移动速度 | 40 像素/秒 |
| 移动方向 | 向左 (面向马里奥) |
| 血量 | 1 |
| 击杀方式 | 踩踏 |
| 击杀奖励 | 100分 |

**行为逻辑**:
- 水平移动，遇到障碍物转向
- 被踩踏后扁平化动画，然后消失
- 碰到小马里奥 → 马里奥死亡
- 碰到大/火焰马里奥 → 马里奥变小

### 4.2 乌龟怪 (Koopa Troopa)

| 属性 | 值 |
|------|-----|
| 尺寸 | 16x24 像素 |
| 移动速度 | 50 像素/秒 |
| 移动方向 | 向左 (面向马里奥) |
| 血量 | 1 |
| 击杀方式 | 踩踏 (变龟壳) |
| 击杀奖励 | 100分 |

**行为逻辑**:
- 水平移动，遇到障碍物转向
- 被踩踏后变成龟壳
- 龟壳可被踢出，沿地面滚动
- 滚动的龟壳可消灭其他敌人
- 滚动的龟壳碰到马里奥 → 伤害

## 八、玩法规则

### 8.1 胜利条件
- 到达终点旗帜

### 8.2 失败条件
- 被敌人碰到 (小马里奥)
- 掉入深渊
- 时间耗尽

### 8.3 计分规则

| 行为 | 分数 |
|------|------|
| 踩死栗子怪 | 100 |
| 踩死乌龟怪 | 100 |
| 龟壳消灭敌人 | 100/个 |
| 收集金币 | 200 |
| 顶出金币 | 200 |
| 顶出蘑菇 | 1000 |
| 顶出火焰花 | 1000 |
| 顶出星星 | 1000 |
| 破坏砖块 | 50 |
| 到达终点 | 5000 + 时间奖励 |

### 8.4 连击系统
- 连续踩敌人: 100 → 200 → 400 → 800 → 1000 → 2000 → 5000 → 8000 (1UP)
- 踩敌人后落地重置连击

## 九、美术风格

### 9.1 整体风格
- **风格类型**: 16-bit像素风 (SFC风格)
- **色调氛围**: 明亮活泼、复古怀旧
- **参考作品**: 超级马里奥世界 (Super Mario World)

### 9.2 色彩规范

| 元素 | 主色调 | RGB |
|------|--------|-----|
| 天空背景 | 天蓝色 | #5c94fc |
| 地面砖块 | 棕色 | #c84c0c |
| 问号砖块 | 金黄色 | #fcbcb0 |
| 马里奥帽子 | 红色 | #e52521 |
| 马里奥衣服 | 蓝色 | #049cd8 |
| 金币 | 金色 | #ffd700 |
| 草地 | 绿色 | #80d010 |

### 9.3 动画风格
- 帧动画，每动作4-8帧
- 动画帧率: 12 FPS
- 跳跃时无动画，落地恢复
